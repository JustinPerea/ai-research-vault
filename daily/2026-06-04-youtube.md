### [Benchmarking semantic code retrieval on Claude Code — Kuba Rogut, Turbopuffer](https://www.youtube.com/watch?v=zKk7sDMGDEQ) — AI Engineer (~25min, category: ai-agents)
**TL;DR:** 50-task ContextBench benchmark: raw Claude Code wastes 1-in-3 file reads; windowed reads drop that to 1-in-5; semantic search drops it to 1-in-8 with file precision 65%→87%.

**Key insights:**
- Concrete numbers for the windowed-read + semantic-search stack: precision lift is real, but matters less for keyword-rich import tracing (grep wins).
- Cursor's production numbers: +24% relative answer accuracy and +2.6% code retention in large codebases from semantic retrieval.
- Why Kuba's gains were smaller than Cursor's: Cursor's model knows when to call semantic search; Claude Code just exposes it as another tool. Tool-routing intelligence matters more than the tool itself.

**Tools mentioned:** Claude Code, Turbopuffer, ContextBench, Cursor

**For /bookmark:** `https://www.youtube.com/watch?v=zKk7sDMGDEQ`
