### 1. Is Complex Agentic Memory Always Needed? Naive RAG Is Stronger Than We Thought
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.30755
- **Authors/org:** Zhengye Bao, Shengtao Zhang, Haokai Zhang, Shiqi Lou, Muning Wen, Minnan Luo
- **Focus area:** agent memory vs naive RAG baseline
- **What it is:** Raw-RAG (dense retrieval + reranking over raw history, fed to a reader LLM) ranks first among compared memory systems in six of seven benchmark-model settings across LoCoMo, LongMemEval, MEME and MemoryAgentBench, beating the strongest agentic memory system by 0.13-5.53 points. Higher evidence coverage offsets lower utilization; even full access to transformed memory stores leaves a gap vs raw evidence.
- **Why it matters for Justin's agents:** Second day running that raw history + retrieval beats designed memory (after Oct 22's MemoryTax). Keep raw logs as the source of truth in Mitamaton and treat any distilled memory as an index, not a replacement; Raw-RAG is the baseline any memory change must beat.
- **Action signal:** `try-now`

### 2. Why Bother Me Again? Benchmarking Personal Agent Memory for Interaction Preferences
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.30485
- **Authors/org:** Jialin Li, Zhenhao Chen, Hanjun Luo, Hanan Salam
- **Focus area:** personal-agent memory for interaction preferences
- **What it is:** MemPABench: interactive on-policy environment where agents must decide when to clarify, confirm or act; four simulated users, 14 preferences, 99 sessions over four months with five event-driven preference changes each. Across four memory systems and four LLM backbones, retrieval-based memory (Mem0, MemOS, simple RAG) does not beat No Memory; file-based memory improves accuracy but over-applies preferences. Even with the right preference available, agents struggle to override default habits.
- **Why it matters for Justin's agents:** Directly Mitamaton's problem ("don't ask me again"). Tests interaction preferences, not facts, and finds file-based memory helps but leaks into wrong contexts — scope preferences by context in the memory file.
- **Action signal:** `try-now`

### 3. Governance-State Corruption in Long-Term Memory for LLM Agents: A Cross-Model Stress Test
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.30698
- **Authors/org:** Bowen Liu, Youting Wang, Bonan Shen, Dingyan Shang
- **Focus area:** memory control-state integrity
- **What it is:** Studies governance-state corruption: faults that change which retained records enter model-visible context (validity state) while stored content stays fixed. Across six providers and 2,080 matched fault pairs, corruption changes the operative projection in 96.25% of pairs; oracle-backed enforcement restores 100%. Clean-minus-corrupted contrasts: 40.54 points on LongMemEval correctness, 30.60 on Memora FAMA.
- **Why it matters for Justin's agents:** Memory validity flags (superseded, expired, revoked) are a separate attack/fault surface from content; enforce them in code, not in the prompt.
- **Action signal:** `compare`

## Conflicts & open questions

- **Designed memory vs raw history.** Raw-RAG (2610.30755) and MemPABench (2610.30485) both find retrieval-based memory systems no better than simple baselines; ColaBench's MemKB (2610.30989) and the subgoal memory graph (2610.31307) report gains from structured memory. Continues Oct 22's MemoryTax vs PreCoMem thread; the structured-memory gains are on synthetic or narrower tasks.
- **Is using memory even wanted?** Memory-aware reward modeling (2610.31272) finds users often prefer memory-free answers; MemPABench finds file-based memory over-applies preferences; State Integrity Collapse (2610.31314) shows remembered constraints stop being applied. Open: whether gating memory use (when to surface) matters more than retrieval quality.
- **Can harnesses improve themselves?** ARC-AGI-3 study (2610.30499) sees no reliable held-out gain from self-revision; HERD (2610.31401) and SPLICE (2610.30790) report gains from harness/skill evolution with distillation. Extends Oct 21-22's self-evolving-harness skepticism.
- **MCP vs CLI.** The comparative analysis (2610.30157) recommends hybrid and says progressive disclosure closes MCP's token gap; the handshake study (2610.30151) measures large per-capability metadata costs when the LLM reads inventories. Both agree on keeping exposed tool inventories small.
- **Multi-agent diversity.** Muffin (2610.31355) shows gains from asynchronous sharing, while herding (2610.30769) and influencer dynamics (2610.31105) show mixed populations collapse toward exposure counts or the largest model. Open: whether shared buffers inherit the same herding.
