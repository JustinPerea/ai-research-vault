# AI Research Digest — Wednesday, October 14, 2026

## TL;DR

- **Skill Routing Collapse** (2610.18522): skill routing collapses at scale — 1,000 distractor skills drop loaded-skill recall 73.6% → 27.4%; explicit preselection keeps 73.9%.
- **Cortex** (2610.14216): gate every CLAUDE.md rule/skill edit on repeated with/without replays; path-scoped rules beat always-offered skills, and gains shrink on Sonnet 5.
- **Grounding Awareness** (2610.18684): a remembered proposal is not consent — persistent memory makes agents execute unacknowledged proposals; track grounding status before acting.
- **Bemula** (2610.18052): no mainstream memory system passes more than 1.5% of user "forget this" requests end-to-end — deletion must be designed in.
- **Memory Echo** (2610.17763): dedupe memory by source family + provenance; FPA lifts accuracy 0.825 → 0.920 by stopping write-back echoes.
- **CarryOn** (2610.18784): persist progress objects instead of compressed history: +5.8% OSWorld 2.0 with 51.9% fewer tokens.
- **TurnCost** (2610.15093): 98.6% of coding-agent input tokens are prefix-cache hits; turn count, not observation size, drives cost (84% vs 4% of variance).
- **SLMs as Interpreters** (2610.14209): cloud writes the program, a local SLM answers bounded questions over private data via a function call — up to +14.9 pp on AppWorld.
- **SchemaWeaver** (2610.17436): schema-guided parallel decoding cuts on-device tool-calling latency up to 3.9×, training-free.
- **DeskIF-Bench / ANIS** (2610.15765): goal-level, discoverable agent-native interfaces beat native SDK use and cut ~73% online tokens.
- **TRAP / ReplayBench** (2610.16333): replayed tool results bound to the wrong context cause unsafe actions (final-state error 0.649); bind results to call context.
- **MCP Metadata Effects** (2610.14334): in MCP, parameter-schema shape moves tool selection more than names/descriptions — design flat, explained params.
- **AuthGateBench** (2610.16426): LLM approval gates (Claude Code / Codex style) block most explicitly authorized actions; environment signals fix much of it.
- **The Agent Knew** (2610.17301): a linear residual-stream probe forecasts unauthorized actions (AUROC 0.94) and gating on it cuts violations 0.70 → 0.09 at orders of magnitude less compute than a CoT monitor.
- **PrivacyGuard** (2610.16778): replace screenshot PII with locally resolvable references for cloud GUI agents — leakage down 33.55–82.60%, Android completion up.
- **Local contract-conditioned rewriting** (2610.18007): local Gemma contract-conditioned rewriting + final checker cuts email-agent leakage 11.41% → 4.03%.
- **Iterate on an LLM, Serve on an SLM** (2610.14576): iterate on frontier prompts, then distill logged production decisions into a LoRA Qwen3-8B (0.913 agreement, ~2.5× faster).
- **Davinci-Tool** (2610.16867): Davinci-Tool lifts Qwen3-Coder-30B-A3B to 88.2 on τ²-bench and 56.2 on MCP-Atlas, beating the 480B sibling.

### 1. When Skills Remain But Access Fails: Factorized Skill Memory for Continual Skill Internalization
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.15492
- **Authors/org:** Haomiao Qiu, Yining Tang, Hongyi Wan et al. (6 authors)
- **Focus area:** skill internalization / continual learning
- **What it is:** Finds two-stage forgetting when skills are internalized continually: first the model loses the ability to address a skill from the raw request (giving the canonical skill name restores it), later execution itself degrades. FSM splits memory into a plastic Address Memory and a stable Execution Memory of frozen per-stage LoRA executors. On a five-stage, 100-skill TaskBench setup: 65.95% mean exact match, 93.38% addressing accuracy, +14.3 pts over the best replay-free baseline and within 1.9 pts of Replay.
- **Why it matters for Justin's agents:** If Mitamaton ever bakes skills into local LoRAs, separate the router (request → skill) from frozen executors — most forgetting is addressing, not execution.

### 2. Lost in Implicit Routing: How LLM Agents Fail to Load Relevant Skills at Scale
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.18522
- **Authors/org:** Jinlin Liu, Wei Chen, Xiaojin Zhang
- **Focus area:** skills / routing at scale
- **What it is:** Holds SkillsBench tasks and golden skills fixed while adding irrelevant skills. ## Conflicts & open questions

- **Implicit skill routing vs compiled skills vs rules.** Skill Routing Collapse (2610.18522) shows recall collapses with large libraries; SkillFusion (2610.15481) merges co-loaded skills offline; Cortex (2610.14216) found auto-loading rules did most of the work and always-offered skills were rarely opened. Open: is preselection + SkillFusion-style merging better than converting high-value skills to path-scoped rules?
- **Self-evolving harnesses vs diminishing returns.** HarnessNet (2610.15221), Harmony Harness (2610.15150), Harness^2 (2610.14224), T2A (2610.16725) and ClawLoop (2610.14118) all report gains; Cortex reports a single run added little under Claude Sonnet 5 and nothing on a real project where the agent was rarely corrected. Same pattern as Monday's Humanize MLE note: harness gains may shrink as models improve.
- **Memory deletion is unsolved — which layer fixes it?** Bemula (2610.18052): no system passes >1.5% of forget requests. Candidates: PolyGraph receipts (2610.17719) for derived artifacts, FPA provenance (2610.17763) for echoes, removable LoRA units in Engram Injection (2610.15882) — which failed on temporal validity. Untested: receipts-based deletion on Bemula.
- **Authorization gates over-block vs under-block.** AuthGateBench (2610.16426) and Same Operation, Different Permission (2610.16838) find gates block authorized actions and that adding reviewers rejects valid authorization; The Agent Knew (2610.17301) gets large violation cuts from a residual probe; Grounding Awareness (2610.18684) says remembered proposals get treated as authorization. Open: combine a grounding-status check with an environment-informed gate without raising false blocks.
- **Can LLM judges localize failures?** Executable Prefix Values (2610.17633) finds judge 'first mistake' labels rarely mark the decisive step and restarting there does not help; Derivation Gap (2610.18497) shows judges follow whatever reference is visible; BLADE (2610.18780) still uses a judge (Jev) but audits information use at handoffs. Conflict on whether judge-based attribution is usable for recovery.
- **Where the cost actually is.** TurnCost (2610.15093) says turns dominate and model delegation raised cost in half of settings under prefix caching; Iterate-on-LLM/Serve-on-SLM (2610.14576) and EC2-Bench (2610.17816) favor delegating to smaller/edge models. Open: TurnCost's break-even rule applied to local SLM delegation where cache locality is lost (CacheLink 2610.15509 targets exactly that handoff).
- **Code-mode tools vs MCP schema effects.** ProgAgent (2610.14774) and DKGI (2610.18616) push tools-as-code / data-as-files; MCP metadata study (2610.14334) shows schema shape drives selection in call-by-metadata. Open: do schema-selection biases persist when tools are invoked programmatically?
