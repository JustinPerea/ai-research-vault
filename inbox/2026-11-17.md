## News and changelogs
- **Claude Code:** v2.1.326 lets Code Mode be turned on while agent teams are enabled (sessions with teams on now start in Code Mode), warns on malformed `--allowedTools`/`--disallowedTools`/`--tools` entries, and explains why MCP servers stop loading when an administrator adds a managed setting — directly affects harness permission config and MCP setup. [link](https://github.com/anthropics/claude-code/releases/tag/v2.1.326)
- **Anthropic API release notes:** Text from Claude Opus 4.6, Opus 4.5, Sonnet 4.5 and Haiku 4.5 carries Anthropic's text watermark on supported platforms; non-default `temperature`, `top_p` or `top_k` may drop the watermark — relevant if agents republish model text. [link](https://platform.claude.com/docs/en/release-notes/overview#text-watermark-claude-opus-4-6-and-4-5-models)
- **Apple Developer:** macOS 27.3 beta 2 adds more transparency and granular options for two APIs, Device Control and Data Access, and for Full Disk Access — privacy/data-access rules that touch any Mac automation or computer-use agent. [link](https://developer.apple.com/news/?id=oqng0zjk)
- **LangChain:** LangChain raises a $300M Series C at a $3B valuation led by CapitalG, to push LangSmith as its agent engineering platform — signals continued investment in agent tooling. [link](https://www.langchain.com/blog/series-c)
- **LangChain:** Harrison Chase on moving from task-specific agents to goal-focused agents — a design direction for long-horizon agents (feed gives only the teaser). [link](https://www.langchain.com/blog/from-tasks-to-goals)
- **LangChain:** LangSmith reorganized around a single agent record so build, run, improve and govern happen in one place on any framework or runtime — an agent-centric observability model to compare. [link](https://www.langchain.com/blog/we-rebuilt-langsmith-around-the-agent)
- **OpenRouter:** Chat models on Hugging Face Inference Providers now route through OpenRouter, and OpenRouter can send traces to a Hugging Face Storage Bucket — a routing/trace export option for open-model agents. [link](https://openrouter.ai/blog/announcements/hugging-face-inference-providers/)
- **Vercel:** AI Gateway now supports Private Inference (no details in the feed) — possibly relevant for privacy-sensitive agent traffic. [link](https://vercel.com/changelog/ai-gateway-now-supports-private-inference)
- **Vercel:** Spend Management now sets budgets for projects and products — a cost cap for agent workloads (no details in the feed). [link](https://vercel.com/changelog/set-budgets-for-projects-and-products-in-spend-management)
- **Vercel:** Hy4 Flash (50% off) and Seedance 2.5 Flash are now on AI Gateway — new model listings, no agent-specific detail. [Hy4 Flash](https://vercel.com/changelog/hy4-flash-now-available-on-ai-gateway-for-50-off) [link](https://vercel.com/changelog/seedance-2-5-flash-now-available-on-ai-gateway)
- **Composio:** @composio/cli 0.6.2 exits with code 75 when a failed request is safe to send again — a clean retry signal for scripted agent tool calls. [link](https://github.com/ComposioHQ/composio/releases/tag/%40composio/cli%400.6.2)
