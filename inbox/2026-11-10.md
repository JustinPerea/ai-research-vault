## News and changelogs
- **Claude Code:** v2.1.322 adds fast mode on Vertex (global, us and eu regions), falling back to standard speed if Vertex refuses it — faster Claude Code sessions for teams routed through Vertex. [link](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)
- **Vercel:** Vercel Sandbox snapshot creation is now up to 10x faster — quicker snapshot/restore for agent sandboxes hosted on Vercel. [link](https://vercel.com/changelog/vercel-sandbox-snapshot-creation-is-now-up-to-10x-faster)
- **Claude Code:** v2.1.321 adds Claude Fable 5.2 (`claude-fable-5-2`) as the default Fable model (1M context, $8/$40 per Mtok, $0.20/Mtok cache reads) and `--settings` for `claude remote-control`; fixes MCP OAuth sending secrets such as refresh tokens to another host on redirect, a read-only Bash command running outside the sandbox without a prompt, wrong-folder Bash write checks, and deny rules/protected-file prompts not applying to `cp`/`mv` into a directory — upgrade: several of these are permission and MCP credential-leak fixes. [link](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)
- **OpenAI:** ChatGPT Enterprise is now available through AWS Marketplace — procurement via existing AWS billing; no API change. [link](https://openai.com/index/chatgpt-enterprise-aws-marketplace)
- **LangChain:** Promptim, an experimental library for prompt optimization — automated prompt engineering that can help when switching models. [link](https://www.langchain.com/blog/promptim)
- **LangChain:** LangSmith Bring Your Own Cloud is generally available on AWS — managed observability, evaluation and deployment inside your own VPC for agent traces that cannot leave it. [link](https://www.langchain.com/blog/langsmith-byoc-is-now-generally-available-on-aws)
- **LangChain:** Explainer on eval-driven development for AI agents: define good behavior, write the eval first, then compare experiments — process guidance, no product change. [link](https://www.langchain.com/blog/what-is-eval-driven-development)
- **OpenAI:** Control Room, a central system that tracks model workloads across OpenAI's research infrastructure and can rapidly stop them on safety or security concerns — a reference pattern for kill-switches over running agent workloads. [link](https://openai.com/index/control-room)
- **Anthropic:** Introducing Claude Fable 5.2 and Claude Mythos 5.2, described as the most capable models for daunting technical work in coding, finance and the sciences — new top model tier for long-horizon agents. [link](https://www.anthropic.com/news/claude-fable-and-mythos-5-2)
- **Anthropic API:** Claude Fable 5.2 (`claude-fable-5-2`) launched for demanding reasoning and long-horizon agentic work; Claude Mythos 5.2 offers the same capabilities only to verified organizations. Both: 1M context, 128k max output, always-on adaptive thinking, $8/$40 per MTok (down from $10/$50 for 5.1); on Claude API, Claude Platform on AWS and Claude Models on Google Cloud — cheaper per-token than 5.1 for agent loops. [link](https://platform.claude.com/docs/en/release-notes/overview#claude-fable-5-2)
- **Anthropic API:** Fable 5.2 and Mythos 5.2 enforce the prefix check for every account: editing the system prompt, tools or an earlier message and then sending back a later-turn thinking block returns a 400 — harnesses that rewrite context or tool lists mid-conversation must be checked before switching. [link](https://platform.claude.com/docs/en/release-notes/overview#claude-fable-5-2)
- **Anthropic API:** On the Claude API and Google Cloud (Google managed), moving a conversation onto Fable/Mythos 5.2 keeps reasoning from other models (incl. Opus/Sonnet/Haiku 5.5); moving away drops the 5.2 thinking blocks and the request still succeeds — matters for model routers that switch models mid-session. [link](https://platform.claude.com/docs/en/release-notes/overview#claude-fable-5-2)
- **Anthropic API:** Fable 5.2 and Mythos 5.2 support computer use only through `computer_toolset_20260801`; declaring `computer_20251124` returns a 400 everywhere except Amazon Bedrock — computer-use agents need the toolset migration. [link](https://platform.claude.com/docs/en/release-notes/overview#claude-fable-5-2)
- **Anthropic API:** With the advisor tool (beta), a Fable/Mythos 5.2 executor accepts only Fable or Mythos 5.2 as its advisor; every executor accepts Fable 5.2 as advisor — set advisor models explicitly when moving executors. [link](https://platform.claude.com/docs/en/release-notes/overview#claude-fable-5-2)
- **Anthropic API:** Both 5.2 models require 30-day data retention and are not available under zero data retention unless Anthropic expressly authorizes it — a data-handling constraint for apps that promise ZDR. [link](https://platform.claude.com/docs/en/release-notes/overview#claude-fable-5-2)
- **Anthropic API:** Thinking blocks from Fable/Mythos 5.2 work only in the producing account or a linked one — multi-account setups cannot replay them across keys. [link](https://platform.claude.com/docs/en/release-notes/overview#claude-fable-5-2)
- **Anthropic API:** Fast mode for Claude Fable 5.2 in the Messages API: up to 2.5x higher output tokens/sec at $16/$80 per MTok via `speed: "fast"`, no beta header — latency/cost trade-off for interactive agents. [link](https://platform.claude.com/docs/en/release-notes/overview#fast-mode-claude-fable-5-2)
