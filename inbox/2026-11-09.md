### 1. Decision Context: Persistent Behavioral Learning for AI Agents
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2611.08644
- **Authors/org:** Nima Vahdat, Pashootan Vaezipoor
- **Focus area:** procedural agent memory / corrections
- **What it is:** forge_dc captures human corrections and self-assessed tool-call failures, compiles them into imperative RULE directives and injects them at the decision points where they apply. DC-Bench: 71 scenarios, 9 behavioural dimensions, built from real executed traces. 95% compliance vs 55% for naive retrieval at ~10x fewer injected tokens.
- **Why it matters for Justin's agents:** Exactly the 'user fixes the same mistake every session' problem for Mitamaton. Store corrections as directives keyed to decision points (tool-call sites), not as more retrievable facts.
- **Action signal:** `try-now`

### 2. When Instruction Files Go Stale: Documentation Debt and Hidden Cost in Coding Agents
- **Source:** arXiv (cross-list)
- **Link:** https://arxiv.org/abs/2611.09802
- **Authors/org:** Tural Mehtiyev, Biruk Tadesse, Lawrence Arkoh, Wesley Assunção
- **Focus area:** stale CLAUDE.md / AGENTS.md instruction files
- **What it is:** Studies three real stale instructions (test command, code location, procedure) over 22 maintenance tasks x stale/corrected/removed, 732 trajectories, two models. Agents follow stale guidance when relevant, even when correct info exists elsewhere; Claude Sonnet 5.5 spent ~2 extra tool calls/run on a stale test command. No agent ever repaired the instruction file.
- **Why it matters for Justin's agents:** Direct hit on Justin's CLAUDE.md-heavy Claude Code stack: task success hides documentation debt. Add a lint/check for paths and commands in instruction files; removing a stale line beats leaving it.
- **Action signal:** `try-now`

### 3. MemoryDojo: Benchmarking Poisoning Through LLM Agent Memory
- **Source:** arXiv (cross-list)
- **Link:** https://arxiv.org/abs/2611.09721
- **Authors/org:** David H. Yang, Blake Bullwinkel, Amanda Minnich, Mohammad Mohammadi Amiri et al.
- **Focus area:** memory poisoning benchmark
- **What it is:** MemoryDojo traces poisoned instructions through agent memory across sessions: 155 multi-session long-horizon trajectories, 4 domains, 5 memory systems. ### 5. Conflux: Preventing Privilege Escalation with Principal Contexts and System-Level Evaluation

- **Authors/org:** Raya Buckley, Christian Schroeder de Witt

### 6. From LoRA to Language: Recovering Skill Documents from Adapters
- **Source:** arXiv (cross-list)
- **Link:** https://arxiv.org/abs/2611.09454
- **Authors/org:** Saranya Dintakurthy Swadha, Pavan C Shekar, Arpit Jain, Aswanth Krishnan
- **Focus area:** skills compiled to LoRA, recovered as text
- **What it is:** Asks whether a skill document can be written back from a LoRA adapter.
