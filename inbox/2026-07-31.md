# AI Research Digest — Friday, July 31, 2026

## TL;DR
- **Zero-Mem** [arxiv:2607.29377] is the cheapest memory paper of the week: **no LLM call and no LLM tokens** for any memory operation except the final question. Original traces stay the source of record; an entity–context graph plus a temporal hierarchy are queried deterministically; calibration drops conflicts before the reader sees them. Competitive quality on long-memory / long-context QA, and **−57.6% memory-operation time** vs the fastest compared baseline at matched reader + context budget. Code earmarked at github.com/TheMoon0815/Zero-mem.
- **AgentStream** [arxiv:2608.00155] is the eval the self-evolving-agent literature was missing: Isolated / Sequential / Interleaved *streams* instead of independent tasks. Five evolution methods × three frontier models. Findings that should change how you read every "self-evolving" claim: reliability **varies by stream shape**, the benefit is **gated by model capability and non-monotonic in model strength**, and **no single method dominates**.

## Items

### 1. Zero-Mem: Zero-Token Memory Operations for LLM Agents
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2607.29377
- **Authors / org:** Yilin Xiao / Zhehan Zhu / Yujing Zhang / Jin Chen / Zijin Hong / Luyao Zhuang / Qinggang Zhang / Shengyuan Chen / Xiaocao Ouyang / Lingfei Ren / Xiao Huang
- **Focus area:** Agent memory (cost / architecture)
- **What it is:** Asks whether structured memory access requires generation. Zero-Mem: **zero-token memory operations** — no step outside final QA invokes an LLM or consumes LLM tokens (encoder compute is accounted separately). Source of record is the original interaction traces, not LLM-written summaries. Two views: an **entity–context graph** (cross-interaction links) and a **temporal hierarchy** (conversational locality + session state). Per query the system weighs the two views, retrieves from both, follows structure for supporting relations, then deterministically discards conflicting evidence before the reader. Only the final-QA reader is an LLM. Competitive on long-memory and long-context QA; with the same reader and context budget, memory-operation time drops **57.6%** vs the fastest compared baseline. Ablations support both views and their query-dependent coordination. Code after review: https://github.com/TheMoon0815/Zero-mem
- **Why it matters for Justin's agents:** mem0 / LangMem / AREX / MSCE all spend tokens to *maintain* memory. On a local 64 GB box and on Anthropic API bills, that is the wrong tax. Zero-Mem is the existence proof that grep + a typed graph + a date tree can replace the maintainer LLM for the retrieve path. Complements Filesystem-Based Memory (Jul 29): that paper said organization buys search economy, not answer quality; Zero-Mem says you can buy the economy *without* a manager LLM. Practical shape for the vault: keep raw notes, maintain `entities.md` + folder-by-month as the two views, retrieve with ripgrep / wiki-links, and only call Claude for the final answer.
- **Action signal:** `try-now` — stop using an LLM to write weekly memory summaries; index the raw daily notes instead and measure tokens-to-answer on a 15-question personal set.

### 2. AgentStream: How Well Do Self-Evolving LLM Agents Perform Under Streaming Tasks?
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.00155
- **Authors / org:** Dong Yan / Jian Liang / Dapeng Hu / Ran He / Nicholas Jing Yuan / Qi Zhang / Tieniu Tan
- **Focus area:** Agent evaluation + self-evolution
- **What it is:** Argues that existing self-evolving-agent papers evaluate tasks *independently*, which is not how a deployed agent sees work. AgentStream organizes agentic benchmarks into a configurable task stream and instantiates **Isolated / Sequential / Interleaved** scenarios that vary scope and domain mix. Combinatorial eval: five representative self-evolving methods × three frontier foundation models. Results: self-evolution reliability varies across streaming scenarios; the benefit is gated by model capability and is **non-monotonic in model strength**; **no single method dominates** across models and scenarios. Code: https://github.com/Jasper-Yan/AgentStream
- **Why it matters for Justin's agents:** Learning on the Job [arxiv:2607.22157], AgentBrew, MSCE, SkillRise, and every "write a skill from yesterday" hook are Isolated-eval papers. Justin's actual week is Interleaved (coding + day-admin + research in one stream). AgentStream is the reason to distrust a method that only wins Isolated, and the reason a weaker local model may *not* inherit a self-evolution recipe that worked on Opus. Use it as the eval *shape* even if you never run their harness: when you test a Mitamaton memory or skill change, run Isolated *and* a mixed Friday stream.
- **Action signal:** `compare` — any self-evolution hook (SessionStop skill write, nightly curator, Learning-on-the-Job rules) gets a three-condition check: Isolated / Sequential / Interleaved, same 10-task set.
