## Items

### 1. AutoSaddler: Automatic Harness Optimization with Durable Updates from Agent Execution Traces
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.23041
- **Authors / org:** Sungho Park / Wonjoong Kim / Rongyuan Tan / Jue Zhang / Wook-Shin Han / Pengfei Gao / Chanyoung Park / Yongqiang Yao / Rao Fu / Elsie Nallipogu / Qingwei Lin / Saravan Rajmohan / Dongmei Zhang — Microsoft
- **Focus area:** Offline harness evolution
- **What it is:** Treats harness improvement as offline learning from failure traces in mini-batches. Failure-trace diagnosis + structured patches that treat the harness as code (Prompt / Tool / Middleware) + validation-based update selection. GAIA2 **+9.0pp**, SWE-Bench Pro **+9.6**, Terminal-Bench 2.0 **+10.0** over the corresponding base harnesses. Ablations: deep debugging > shallow reflection; targeted modifications > unconstrained editing; generalization-aware selection > trajectory-specific repair. Code: github.com/microsoft/AutoSaddler. Submitted Aug 24; abs verified.
- **Why it matters for Justin's agents:** PILOT [arxiv:2608.26530] (08-28 digest) steers the *current* run. AutoSaddler evolves the harness *between* runs from failures. Complementary, not competing — a Mitamaton loop wants both a live supervisor channel and a Friday patcher that only keeps patches that generalize. Three ingredients are portable even if you never run the trainer: debug the failure, patch a typed surface, validate on held-out tasks.
- **Action signal:** `try-now` on the three-ingredient loop for Claude Code skill edits; `compare` against PILOT before merging live-steer and offline-evolve.

### 2. SecOPD: Mitigating Adaptive Prompt Injections by On-Policy Distillation
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.21500
- **Authors / org:** Yibo Peng / Long Lian / David Wagner / Sizhe Chen — UC Berkeley
- **Focus area:** Model-level prompt-injection defense
- **What it is:** Sequence-level DPO/GRPO cannot tell the model *which tokens* are insecure. SecOPD scores a rollout's tokens with the initialization model on the *clean* input (token-level teacher). Defended Qwen3.6-27B: PISmith adaptive ASR **9.0%** vs Meta-SecAlign **94.0%**; agentic tool-calling ASR **4.7% vs 5.5%** with utility preserved. Code: github.com/pppyb/SecOPD; weights: huggingface.co/pybbb/Qwen3.6-27B-SecOPD. Submitted Aug 21; HF Daily Aug 26; abs verified.
- **Why it matters for Justin's agents:** Fourth MCP-security layer this week: HarnessRisk (config), APC (composition), SARA (observation-authorization), SecOPD (token-level model defense). If you serve a local Qwen for Mitamaton tool-calling, the 27B-SecOPD checkpoint is the try-now weights. SARA still belongs at the executor; SecOPD does not replace argument-level authorization.
- **Action signal:** `try-now` on the Qwen3.6-27B-SecOPD weights if you already host 27B; `compare` against SARA/APC as complementary, not substitutes.

### 3. AgentRoom: Concurrent Multi-Agent Coding in a CRDT-Backed Shared Workspace
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.23740
- **Authors / org:** Seonglae Cho / Donghyun Lee
- **Focus area:** Multi-agent coding coordination (MCP)
- **What it is:** File-level claim, status, and broadcast as MCP tools on a CRDT-merged shared filesystem. Five frontier coding-CLI models × four backend tasks (+ Python / Rust+axum checks). For CLI-stable models, AgentRoom with 2 agents abandons fewer tasks than Solo and has less run-to-run variation. Matched-compute: one LLM-judge contrast puts AgentRoom over parallel-merge; a bundle probe ranks full AgentRoom above each partial case. **Coordination, not parallelism or CRDT-merge, bears the load.** Project: seongland.com/article/agentroom. Submitted Aug 24; abs verified.
- **Why it matters for Justin's agents:** If two Claude Code sessions edit the same vault, file-level claim > silent overwrite. The result is a protocol (claim / broadcast / merge), not a reason to spin more agents. CRDT without coordination is parallel-merge, which loses.
- **Action signal:** `compare` — add a file-claim convention for concurrent Claude Code sessions; skip the CRDT runtime until two sessions actually collide.
