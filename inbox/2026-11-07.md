## News and changelogs
- **Vercel:** Chat SDK agents can now stream generative UI with json-render — streamed UI from chat agents, relevant to multi-platform agent front-ends. [link](https://vercel.com/changelog/json-render-and-chat-sdk-agents)
- **Vercel:** AI Gateway adds DeepSeek Search and Fetch tools — gateway-provided web search/fetch tools for agents routed through AI Gateway. [link](https://vercel.com/changelog/ai-gateway-adds-deepseek-search-and-fetch-tools)
- **Vercel:** Vercel CLI can now set new projects to expire — useful for throwaway agent-created preview projects. [link](https://vercel.com/changelog/vercel-cli-can-now-set-new-projects-to-expire)
- **Claude Code:** v2.1.319 — when an MCP server runs a tool call as a task, Claude Code now moves it to the background and reports the result when it finishes (`CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND` opts out); new `permissions.denyInsteadOfPrompting` denies calls that would wait on a permission prompt so unattended turns, subagents and teammates keep going; auto mode behind LLM gateways no longer falls back to the built-in classifier (`CLAUDE_CODE_AUTO_MODE_SERVER=0` keeps it); adds `/claude-api latency-optimize`. Directly relevant to headless/nightly Claude Code jobs and long-running MCP tools. [link](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)
- **Vercel:** Vercel Tracing is now generally available — tracing for deployed functions, useful for debugging agent backends. [link](https://vercel.com/changelog/vercel-tracing-is-now-generally-available)
- **OpenAI:** Partnering with Hacktron to find vulnerabilities, test connections with third-party services and strengthen defenses with frontier AI — a security-agent signal for third-party integrations. [link](https://openai.com/index/partnering-with-hacktron)
- **Anthropic:** Teaching AI to build scientific models — research post (no summary in feed). [link](https://www.anthropic.com/news/teaching-ai-to-build-scientific-models)
- **OpenAI:** BioBasicsBench — a 100-task benchmark of how well AI agents interpret raw experimental data and handle everyday wet-lab science; domain agent eval, outside Justin's lane. [link](https://openai.com/index/measuring-how-ai-agents-handle-wet-lab-science)
- **OpenRouter:** New Auto and Auto Code routers — Auto Router rebuilt plus a coding-specialized Auto Code; both weigh eleven factors per request (live pricing, provider health, benchmarks, cache state) to pick a model and reasoning effort within your governance-allowed pool. Worth comparing against fixed model routing for agent calls. [link](https://openrouter.ai/blog/announcements/auto-and-auto-code-routers/) · **Vercel:** Ampersand from Humans& now available on AI Gateway.
