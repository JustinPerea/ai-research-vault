# AI Research Digest — Wednesday, November 25, 2026

## TL;DR
- **Irreducible Governance** (track) — Keep admission control for which subagents may act separate from execution-time guards.
- **ContextLure** (compare) — Do not let earlier benign turns justify a later unauthorized tool action; authorize against policy, not conversation evidence.
- **Learning What vs. Learning How** (compare) — When fine-tuning a small tool-using model, add rehearsal traces on the exact harness format you deploy.
- **Taxi** (compare) — Store agent steps in a queryable table and cluster them to find recurring failure modes.
- **Frontier-model agent skills on open-weight models** (try-now) — Run your skills against a local open-weight model in an automated harness and feed failures back into the skill text.
- **One Step, Four Clocks** (compare) — Before executing a GUI action decided earlier, re-check whether the screen changed and update or replace it.
- **Agent Recovery Gone Wrong** (try-now) — Derive operation identity from call content for idempotency instead of trusting model-issued identifiers.
- **TACT-Bench** (compare) — Evaluate agents on matched adversarial and benign task pairs, not refusal rate alone.
- **AGL-SKILL** (try-now) — Point a coding agent at a skill file with a measurable score and let it iterate.
- **CAPE** (track) — Probe a tool's hidden parsing settings with a few cheap calls before committing to a call plan.
- **ExpGuard** (compare) — Score a stored experience's risk at retrieval time using provenance, not only relevance.
- **BiDE-Mem / MemPath** (compare) — Decompose a question into typed constraints (fact, relation, time, state) and retrieve until each is covered.
- **The Control-Flow Tax** (compare) — Measure how much of your agent's spend goes to deciding what to do and route those decisions to a small model.
- **VISE** (try-now) — Diff a skill's instructions against the tool code it calls to find missing or conflicting steps.
- **ShellBench** (compare) — Spend effort on model selection and tasks before harness swaps for everyday-task agents.
- **RecordRoute** (track) — Localize the earliest decisive step first, then diagnose only that record.
- **Delegent** (try-now) — Hand investigate/test/search subtasks to a small local subagent and keep the frontier model as the lead.
- **RECAP** (compare) — Judge a compaction by whether the agent behaves the same afterwards, not by how it reads.
- **SD-Cache** (track) — Cap KV memory with a learned fixed-size consolidation rather than keeping every retrieved document's cache.
- **MIMPA** (compare) — Treat retrieved 'successful' team records as untrusted input to later tasks.
- **Scoring Recovery-Time Agent Security** (compare) — Tell the agent explicitly how to check whether a timed-out write committed before retrying.
- **Per-Attack Blocking Hides Catalog Vulnerability** (try-now) — Report catalog-level exfiltration paths, not per-attack block rate, when auditing an MCP tool set.
- **Where Agent Defenses Fail** (compare) — Measure effects from files and network receipts, not from the agent's own control logs.
- **LatentLens** (track) — Keep decoded text between agents unless latent exchange is shown to beat it on your harness.
- **Where is the Interface for the AI Harness?** (track) — Make the permissions and checks of an agent harness visible and editable by the end user.
- **Learning Compact State Abstractions** (compare) — Replace full interaction history with an inspectable state program and measure what it drops.
- **Calm Agent** (track) — Keep a persistent task representation the user can glance at to see state and adjust.
- **PATH** (track) — Predict approval for a permission from the user's decisions on its parent categories.
- **LLM Agent Authorization Across Context Compaction** (try-now) — Derive authorization only from text the user actually wrote, never from a compaction summary.
- **When Answering Is Administering** (try-now) — Accept permission-update replies only if they keep every denied call denied, or record who wrote each rule.
- **DarkAgent** (track) — Do not rely on browser fingerprint checks alone to tell agents from humans.
