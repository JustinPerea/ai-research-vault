## Items

### 1. AgentMercury: Your Agent Can Synthesize Verifiable Environments for Business Scenarios at scale
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.20634
- **Authors / org:** Minbyul Jeong — Meridian Intelligence Global; Chanwoong Yoon — UMass Amherst
- **Focus area:** Scenario-grounded environment synthesis + agent RL
- **What it is:** Treats world construction as a first-class *Planet* role: a high-level business scenario becomes a persistent world (entities, services, tools, state, executable cross-service invariants) from which many tasks can emerge. **4,783** executable environments spanning 14 industries and 50 countries; RL corpus 43,300 tasks. Despite *not* targeting the eval benches, Qwen3.5-4B GRPO: EnterpriseOps-GYM **12.3 → 15.7**, AIME26 **45.9 → 56.0** (also HMMT 28.5→35.4, LiveCodeBench 36.6→44.0, SciCode 22.6→25.7). Fine-tuning Qwen3.5-35B-A3B on construction traces: held-out authoring **3.3% → 83.3%** (matches API-model zero-shot). Deterministic SQL-style graders; MCP environments. HF Daily Aug 24; abs/html verified this run.
- **Why it matters for Justin's agents:** Mitamaton's job is a multi-service business world (calendar, mail, files, notes) with cross-service invariants ("if I moved the meeting, the travel block must move"). AgentMercury says scale the *world*, not the task list — and that a 4B local model can pick up transferable tool-use from synthetic company workflows. The authoring result (3.3→83.3) is the other half: Claude Code can be taught to *write* the sandbox, not just act in one. Complements SPADE (writes Gym envs) and EnvHarness (wraps a frozen env).
- **Action signal:** `compare` — against SPADE / EnvHarness as the env-gen stack; steal the "invariants are graders, not transition rules" split for Mitamaton contracts.

### 2. ParaTempo: Efficient Parallel Reasoning via Temporal Confidence
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.16425
- **Authors / org:** Xuteng Zhang / Wenhao Zeng / Xiaodong Gu / Chao Hu / Haotian Lin / Yuling Shi / Min Wang / Beijun Shen — SJTU
- **Focus area:** Test-time parallel reasoning (cost)
- **What it is:** Training-free asynchronous parallel reasoning. Each branch is periodically probed for a tentative answer distribution; **temporal confidence** is how sharply recent probes concentrate on a dominant answer. One signal drives the whole controller: prune low-confidence, retire persistently concentrated, fork from high-confidence donors, stop when the confidence-weighted vote concentrates. No inter-trajectory sync. Math/science benches: average latency **−21.8 to −32.2%**, total tokens **−18.1 to −30.3%**, competitive accuracy. Temporal confidence is more stable and more predictive of future convergence than token-level or instantaneous probes. Code: github.com/ScottZhang812/ParaTempo. Submitted Aug 17; HF Daily Aug 24; abs verified.
- **Why it matters for Justin's agents:** Parallel reasoning is how expensive models eat the 64GB / API budget. ParaTempo's portable piece is the *controller signal* (sliding-window answer-space concentration), not a new sampler. Direction-dependent: prune the lost, retire the committed, fork from the confident. Useful for Mitamaton "leave now?" / planning forks where you already run two drafts.
- **Action signal:** `try-now` — steal temporal-confidence early-stop for any parallel draft; `compare` against naive self-consistency@N.

### 3. Llama-Mobile: Efficient 2.7-Bit Quantization of VLMs
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.21134
- **Authors / org:** Luka Ribar / Jeevan Bhoot / Douglas Orr
- **Focus area:** On-device VLM compression
- **What it is:** Quantization pipeline that uses the model itself to generate training data (no original training setup) plus a **2.7-bit-per-parameter** format designed for efficient Arm CPU execution. Llama 3.2 11B Vision Instruct compressed to **3.7 GB** with 8-bit activations, preserving strong VQA performance. Submitted Aug 21; abs verified.
- **Why it matters for Justin's agents:** Real open-weight compression recipe at phone-class size. Caveat: **Arm CPU SIMD-lookup format, not Apple Silicon / MLX**. Do not assume a drop-in on M5 Max. The self-generated-data QAT pipeline is the portable piece if you ever need a camera-using Mitamaton path. 11B @ 3.7 GB is the existence proof that a vision day-admin model can fit in RAM next to a 30B-A3B text model if the format cooperates.
- **Action signal:** `try-now` on the self-data QAT idea; `compare` against MLX / llama.cpp quants before any iOS port.
