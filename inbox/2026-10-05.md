# AI Research Digest — Monday, October 5, 2026

## TL;DR

- **DyadMem** (2610.03020): relationship memory ("how this agent works with this user") benchmark; gold-memory QA strong, full-pipeline QA drops sharply across 20 models, with low capture recall and unsafe deletion — the write path is where Mitamaton memory breaks.
- **WebFovea** (2610.03036): same model, harness-only changes took a live-web agent from 31.0 to 57.0 (modulo live-site variance); a 3/4 coordinate-scaling bug and silent dropdown/iframe failures were the culprits — audit the GUI loop first.
- **VERSE** (2610.02616): self-evolving harness optimizers only help with execution-based verification; gate skill/hook edits on replay.
- **Sentry** (2610.02994): keep failure lessons out of context and retrieve them only on detected failure — +37% vs runtime intervention, +39% vs context evolution (on the two shared benchmarks); full playbook in context hurts.
- **DeskForge** (2610.02320): 1.2M-observation desktop corpus; a released Qwen3.5-4B grounding model gains +11.51 pp ScreenSpot-Pro — a realistic local computer-use part.
- **PACE** (2610.02932): when to compile repeated GUI chores into programs; payback in 2-16 uses, ~17% token savings vs ReAct.
- **APDMem** (2610.02472): four-layer progressive-disclosure memory hits strong LongMemEval while touching 8% of conversations.
- **GHOST** (2610.02664): long-horizon agents break safety constraints stated many turns earlier (11.5% on GPT-5.5); re-inject and audit standing rules pre-execution.
- **Action Calibration** (2610.02769): agents ignore action→outcome links in history; simply labeling each observation with its action improves success — free transcript-format fix.
- **Email agents** (2610.02627): indirect/formal phrasing makes email agents silently omit required actions — test phrasing variants for day-admin.
- **SideKernel** (2610.02456): open-source local microVM sandbox for coding agents on macOS.
- **FinSkillBench** (2610.03564): curated skills +16.2 pts, self-generated skills +0.5; executable tools (+19.5) beat docs (+5.6).
- **Pincer** (2610.02569): a digital-twin proxy that learns user-specific least-privilege policies to answer agent permission requests.

### 1. VERSE: Verified Self-Evolving Optimizer for Agent Harnesses
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.02616
- **Authors/org:** Zekai Wang, Yingqiang Ge, Zekun Wang et al. (9 authors)
- **Focus area:** skills / harness evolution
- **What it is:** Self-evolving harness optimizer that tests draft edits, replays failures and perturbs suspected steps before submitting, and revises both the executor harness and its own prompts, skills, tools, hooks and notes (weights fixed). Best validation-selected harness: 42.3% / 37.7% on held-out SWE-rebench and newer OOD tasks vs 39.2% / 29.3% for the strongest baselines.
- **Why it matters for Justin's agents:** Key finding for any self-improving Claude Code setup: optimizer self-evolution fails without execution-based verification. Gate every skill/hook edit on replay, not on the optimizer's own judgment.
- **Action signal:** `try-now`

### 3. Knowledge or Calculator? Decomposing the Skill Premium in Verifiable Financial Agent Workflows
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.03564
- **Authors/org:** Jermyn Zhen Yong Bek, Zhuang Qiang Bok, Zhongtian Sun
- **Focus area:** skills / harness evolution
- **What it is:** 2,603 point-in-time finance episodes, 17,820 runs across 9 models. Curated skill packages add +16.2 points (0.366 → 0.528); skills generated within one episode add only +0.5 while costing more tokens/turns. ### 4. Harness-Aware Distillation for Small Language Model Agents

## Conflicts & open questions

- **Lessons in context vs out of context:** Sentry finds exposing the full failure playbook lowers performance, while GraphMemory and Inherit-MAS keep accumulating reusable strategies/results — the difference may be retrieval scope (bounded subgraph / exact-context match) rather than accumulation itself. Mitamaton should retrieve lessons conditionally, never append-all.
- **Harness vs model as the lever:** WebFovea attributes a 31.0→57.0 jump to harness changes (same model) and VERSE/FinSkillBench say gains are system properties; EvoRiskBench finds security ASR varies more across models than harnesses. Capability looks harness-bound, security looks model-bound — test both axes when swapping in open models.
- **Cheap classifiers as gates:** SLM task-tool intent matching proposes small models for per-call oversight, but System-1 Decision Models shows an open-weight classifier flips 30% of answers on option reversal and collapses at 50 similar tools. Any local tool-gate needs order-randomized and large-catalog tests before trust.
- **Summaries vs turning points:** Interpreting at Write Time favours per-goal summaries; TPBench shows any compression below full context loses late user corrections, with plain recency the best compressed method. Per-goal summaries still need pinned revision turns.
- **Plan-then-execute security:** COBRA shows Dual-LLM planning leaks via branch steering in GUIs; STAR-Guard and Pincer add deterministic audits / learned least-privilege. No single layer is sufficient — expect to stack capability bounds, constraint restoration and permission proxies.
- **Self-generated vs curated skills:** FinSkillBench finds in-episode generated skills add +0.5 pts while curated ones add +16.2; VERSE reports optimizer self-evolution helps only with execution-based verification. Open question: does verified self-evolution close the gap to curated skills?
