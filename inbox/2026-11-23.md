# AI Research Digest — Monday, November 23, 2026

## TL;DR
- **AstronautBench** (compare) — Score memory-carryover agents on whether each answer cites evidence they actually observed, not just on answer accuracy.
- **Self-Evolving Beyond Human-Crafted Experience for EDA Scripting** (track) — Gate any agent-written memory entry behind a held-out replay and rollback before it is retrievable.
- **Keep the Process, Change the Supplier** (compare) — Record 'unknown outcome' for tool calls whose reply was lost and never blindly retry them across suppliers.
- **Run One, Get Two** (track) — Run a safety guard as a co-decoded row on the local model rather than a separate guard model.
- **MixFold** (track) — Pick quantization formats by what the target NPU executes natively, not by bit count alone.
- **Actions Speak Louder than Words** (compare) — Fetch resources under a fixed budget independent of private context and choose from a local snapshot.
- **CoEvoBench** (track) — Treat harness and model changes as one search problem when automating agent improvement.
- **TOUMAII** (try-now) — Run DPO on matched correct/incorrect tool-call pairs after SFT for small tool-calling models.
- **Who Grades the Agent? Privilege Separation for Coding-Agent Benchmarks** (compare) — Run tests in the agent sandbox but judge results in a separate trusted process holding the expected answers.
- **TEA-Bench-BR** (track) — Test coding agents against hidden mutant-killing cases rather than visible examples.
- **Search-RSI** (track) — Grow training tasks together with their evidence so unreachable negatives do not penalize the policy.
- **From Acting to Learning** (track) — Select which stored trajectories to train on by gradient utility rather than randomly.
- **HookEvo** (compare) — Evolve hook handlers and the state they share together instead of prompt text alone.
- **Bel** (compare) — Render each candidate tap onto the screenshot and score it visually before executing.
- **ProbeAgent** (compare) — Re-run the agent on variants preserving a suspected failure cause to confirm it recurs.
- **Tracking and Limiting Unsupported Claim Propagation in Multi-Agent LLM Systems: A Provenance-Aware Framework** (track) — Attach support status, source and transmission history to every claim handed between agents.
- **Contexture** (compare) — Evict tool outputs that later operations supersede, keeping full history outside the model context.
- **Privacy Protection in Self-Evolving Personal Agents: Persistent Memory and Cross-Carrier Transfer** (track) — Track lineage for each private memory so withdrawal can reach derived skills and summaries.
- **Exercised, Rarely Recovered** (try-now) — Test checkpoint/resume and rollback in your harness with deliberate failures before relying on them.
- **Epistemic Guard** (try-now) — Route MCP calls through an out-of-process proxy that signs receipts and checks agent prose against them.
- **Do Senior Agents Do Their Job? Measuring Role Integrity in How LLM Agents Use Subordinate Material** (compare) — Have orchestrators verify subagent claims and carry their limitations forward explicitly.
- **Correct Precedents Induce Policy Violations in On-Device LLM Agents** (try-now) — Re-check each restricted item's status instead of letting prior in-session decisions carry over.
- **Learning When to Ask** (compare) — Train small agents to call a stronger advisor only when uncertain.
- **Belief-State Management Meets Rubric Rewards for Agentic Forecasting** (compare) — Give long-running agents a fold tool that rewrites context into a belief state.
- **Schema-Validated LLM Workflows** (compare) — Score task correctness separately from schema validity for structured outputs.
- **Embodied-Harness** (track) — Separate short-term execution context from long-term experience and reflect on observed evidence.
- **VMSA** (track) — Induce reusable retrieval skills from successful agent trajectories.
- **Fix Where It Fails** (track) — Diagnose where the model fails before asking an agent to search harness edits.
- **CodeReviewBench** (track) — Use acted-on suggestions as a free quality signal for code-review agents.

## Items
### 1. AstronautBench: Measuring Agent Self-Improvement Across Episodes Through Knowledge, Evidence, and Progress
- **Source:** arXiv (new submission)
- **Link:** https://arxiv.org/abs/2611.26910v1
- **Authors/org:** Congyuan Yu, Runping Tian
- **Focus area:** Memory / agent evaluation
- **What it is:** Benchmark on Outer Wilds that scores agent self-improvement across 22-minute episodes through three views: places and facts reached, QA correctness on 164 questions, and whether answers are supported by the agent's own cited evidence.
- **Why it matters for Justin's agents:** Gives a way to check that an agent's memory carryover is real learning, not unsupported correct answers; useful for evaluating Mitamaton's cross-session memory.
- **Action signal:** compare

### 2. Self-Evolving Beyond Human-Crafted Experience for EDA Scripting
- **Source:** arXiv (new submission)
- **Link:** https://arxiv.org/abs/2611.26912v1
- **Authors/org:** Yang Liu, Shengbo Tong, Xiyuan Chen, Shiwei Hou, Sen Yuan, Hao Wang, Yanfeng Li, Hongwen Li, Yiming Zhu, Zhuolun He, Wenjian Yu
- **Focus area:** Harness / self-evolving memory
- **What it is:** ZhuLong-SE: an EDA scripting agent whose harness adds API retrieval, sandboxed execution and static checks, plus governed cross-task self-evolution into a three-tier memory store.
- **Why it matters for Justin's agents:** The governance gates (ground-truth anchoring, disconfirmation filtering, held-out rollback) are a concrete template for letting an agent write its own skills/memory without drift.
- **Action signal:** track

### 3. Keep the Process, Change the Supplier: Runtime Governance for Tool-Using AI Agents
- **Source:** arXiv (new submission)
- **Link:** https://arxiv.org/abs/2611.26966v1
- **Authors/org:** Deepak Waghmare, Shaad Sufi
- **Focus area:** Runtime guards / tool-use
- **What it is:** Open Process Control Plane (OPCP): an execution boundary that mediates agent capability calls, separates proposals from business-controlled authority and records uncertain outcomes such as lost replies after commit.
- **Why it matters for Justin's agents:** Retry-all duplicates effects after a lost reply; an idempotent, record-keeping tool boundary is directly relevant to an iOS day-admin agent that books or sends things.
- **Action signal:** compare

### 4. Run One, Get Two: Near-Free Streaming Safety Checks for Local LLMs
- **Source:** arXiv (new submission)
- **Link:** https://arxiv.org/abs/2611.26975v1
- **Authors/org:** Soheil Zibakhsh, Pedram Aghazadeh, Farinaz Koushanfar
- **Focus area:** Local models / runtime guards
- **What it is:** ToRA: an adapter that runs a second model as an extra row in the generator's decode step, sharing weights and KV cache, for near-free streaming safety checks on local LLMs.
- **Why it matters for Justin's agents:** Shows a guard for on-device assistants can cost under 4% latency instead of doubling it.
- **Action signal:** track

### 5. MixFold: Sub-4-Bit Mixed-Precision LLM Inference via Output-Channel Grouping on Mobile NPUs
- **Source:** arXiv (new submission)
- **Link:** https://arxiv.org/abs/2611.26976v1
- **Authors/org:** Vinnam Kim, Seong Hoon Seo, Junhan Kim, Jaeseong You, An Chen
- **Focus area:** Local / on-device models
- **What it is:** MixFold: sub-4-bit mixed-precision LLM decoding on mobile NPUs using native integer ops and output-channel-group datatype assignment, tested on Snapdragon 8 Elite Gen 5 Hexagon.
- **Why it matters for Justin's agents:** On-device decode speed and energy bound what an iOS-style personal agent can run locally; this is Android/Qualcomm, so it is a reference not a drop-in.
- **Action signal:** track

### 6. Actions Speak Louder than Words: Stateful Privacy Sniffing of LLM Agents via Behavioral Covert Channels in Web Interactions
- **Source:** arXiv (new submission)
- **Link:** https://arxiv.org/abs/2611.27046v1
- **Authors/org:** Ruichao Liang, Wenzhong Deng, Jing Chen, Yuqing Li, Kaixuan Li, Cong Wu, Yang Liu
- **Focus area:** Agent security / privacy
- **What it is:** SNOOP: a probing framework that reconstructs a web agent's private query and user profile from the pages it chooses to visit (a behavioral covert channel), plus a defense, Selection-Obfuscated Retrieval.
- **Why it matters for Justin's agents:** Browsing agents with memory leak context through behavior even when no content is sent; content filters do not catch it.
- **Action signal:** compare
