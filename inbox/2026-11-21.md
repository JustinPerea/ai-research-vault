## News and changelogs
- **Claude Code:** v2.1.330 adds sign-in to organizations managed in Anthropic's Enterprise Admin Console (Claude Code then applies the org's settings and cloud provider or gateway), adds easel, a built-in mod that draws charts on request and under MCP metrics results, adds `--start-dir` / `SELF_HOSTED_RUNNER_START_DIR` for self-hosted runners, notices when a plugin marketplace or plugin repo can't be fetched, and adds `commandPrinted`/`commandFailed` to `claude plugin install --json` — useful for scripted harness setup and plugin installs. [link](https://github.com/anthropics/claude-code/releases/tag/v2.1.330)
- **Composio:** @composio/cli 0.6.3 stops `composio proxy` and `composio execute` from hanging for minutes when an agent harness runs them with a stdin pipe it never closes (`proxy` reads a body from stdin only with `-d -`), and adds a `release-manifest.json` so `composio upgrade` installs exactly the listed files — a direct fix for agents shelling out to Composio. [link](https://github.com/ComposioHQ/composio/releases/tag/%40composio/cli%400.6.3)
- **Composio changelog:** SDK release with `@composio/core` / `@composio/slim` 0.31.0 and Python `composio` 0.34.0: pick which Composio-managed app an auth config uses via `managedAppId` / `managed_app_id`, and require CrewAI 1.15.42+ so the CrewAI provider no longer pulls a vulnerable ChromaDB by default — more control over tool auth for multi-tenant agents. [link](https://docs.composio.dev/docs/changelog/2026/11/20)
- **Vercel:** Vercel Functions now support request bodies up to 20MiB (no details in the feed) — room for larger agent payloads such as images or documents. [link](https://vercel.com/changelog/vercel-functions-now-support-request-bodies-up-to-20mib)
- **Gemini API changelog:** Genie 4 (`genie-4`) is GA on the Interactions API (`v1beta`) for real-time interactive world generation, streaming steerable 24 fps video with stereo audio over WebRTC and WebSockets, seeded from text or an image, at $1.50 per 1M input tokens and $17.50 per 1M video output tokens (~$0.10/sec) — little direct agent-platform angle. [link](https://ai.google.dev/gemini-api/docs/changelog#11-19-2026)
- **OpenAI news:** OpenAI describes its layered approach to adversarial distillation (training, safeguards, detection and enforcement against capability extraction) — a vendor policy notice relevant to how model outputs may be used. [link](https://openai.com/index/combatting-adversarial-distillation)
- **OpenAI news:** MedChemBench evaluates how well AI models interpret molecular structures, reason from experimental evidence and select compounds in early drug discovery — no agent-platform angle. [link](https://openai.com/index/introducing-medchembench)
- **Anthropic news:** Anthropic announces the closing of its initial public offering, including full exercise of the underwriters' option to purchase additional shares, and a concurrent private placement — company news, no build impact. [link](https://www.anthropic.com/news/ipo-close)
