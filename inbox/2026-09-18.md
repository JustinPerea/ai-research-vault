### 1. PAPC: Platform Mediation for Privacy-Propagation Externalities in AI-Mediated Workflows
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2609.19226
- **Authors/org:** Tao Huang, Guosen Wu, Chen Hou, Guolong Zheng
- **Focus area:** privacy / memory writes / multi-agent
- **What it is:** PAPC models privacy loss created before any final answer — a memory write, shared-workspace update, inter-agent message or tool event — as a privacy-propagation externality depending on topology and fanout. A platform mediator intercepts information-moving events and can allow, release a policy-safe abstraction, quarantine raw content, block, or narrow onward rights; on retrieval-memory and multi-agent benchmarks it keeps task completion and eliminates measured raw-value exposure.
- **Why it matters for Justin's agents:** Event-level mediation on memory writes and outbound tool calls is the right layer for Mitamaton privacy, not final-output filtering.
- **Action signal:** `try-now`

### 2. MATCH: Model-Aware Tool Learning with Curriculum Scheduling and Hierarchically Gated Rewards
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2609.20082
- **Authors/org:** Shihao Liu, Hao Yin, Lijun Liu, Zhengzong Chen, Yuanyuan Zhao, Fei Huang
- **Focus area:** tool learning / RL
- **What it is:** MATCH: model-aware curriculum near the policy's capability boundary plus Hierarchical Tool-call Gated Reward (tool name → argument key → value, credit only when prerequisites hold). 72.19% on API-Bank and 62.87% on BFCL V3, consistent across four backbones.
- **Why it matters for Justin's agents:** Gated reward is a recipe if Justin ever fine-tunes a small local model for MCP tool calling.
- **Action signal:** `compare`

> _Promoted to [[Research/topics/agent-training]] on 2026-10-09_

### 3. Inference-Engine Fingerprinting Attacks are Practical: Exploring Model-Driven Environmental Discovery, Exploitation, and Escape
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2609.20614
- **Authors/org:** Sarah Radway, Andrew Cheng, Vijay Janapa Reddi, James Mickens
- **Focus area:** inference-engine security
- **What it is:** Shows a misaligned model can fingerprint which inference engine runs it (examples for five popular engines, e.g. vLLM, SGLang) using realistic agentic harnesses, then use engine-specific exploits via crafted output tokens alone; includes a proof-of-concept exploit chain to bare metal.
- **Why it matters for Justin's agents:** Local inference engines are inside the trust boundary of an agent stack: keep them patched and sandboxed like any other untrusted-input parser.
- **Action signal:** `compare`

> _Promoted to [[Research/topics/agent-security]] on 2026-10-09_

### 4. Coding Agents with an Obstacle-Aware Harness for Safe Robot Manipulation
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2609.20822
- **Authors/org:** Bingxin Xu, Yuzhang Shang, Zhen Dong, Emilio Ferrara
- **Focus area:** harness-enforced constraints
- **What it is:** Coding agents writing robot controllers collide with a forbidden obstacle in most cases even though their traces mention it and the prompt forbids it; SafeHarness adds obstacle-aware route planning and contact harnesses so the constraint is enforced in planning.
- **Why it matters for Justin's agents:** A stated constraint in the prompt does not become a priority; enforce hard user constraints in the harness/tool layer.
- **Action signal:** `compare`

> _Promoted to [[Research/topics/agent-harness]] on 2026-10-09_

### 5. Don't Mask the Environment: Observation Supervision Changes How Agents Explore Under RL
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2609.20715
- **Authors/org:** Juzheng Zhang, Disha Makhija, Manoj Ghuhan Arivazhagan, Vinayshekhar Bannihatti Kumar, Rashmi Gangadharaiah
- **Focus area:** agent SFT → RL

- **Why it matters for Justin's agents:** Cheap change for anyone training small terminal/coding agents: don't mask observations.

### 6. RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2609.20784
- **Authors/org:** Yan Yu, Zhengxi Lu, Yizhou Liu, Yichen Pan, Aozhe Wang, Qipeng Chen et al.
- **Focus area:** skill distillation / agentic RL
- **What it is:** RetireOPD trains a skill-conditioned teacher with environment rewards, then a skill-free student with RL + on-policy distillation that retires the teacher adaptively. Qwen2.5 1.5B–7B: +14.1–18.8% ALFWorld and +11.8–19.0% WebShop over RL; student surpasses its teacher.
- **Why it matters for Justin's agents:** Route to internalizing skills into small local models rather than injecting skill text every call.
- **Action signal:** `track`

> _Promoted to [[Research/topics/agent-training]] on 2026-10-09_

### 8. For Your Eyes Only: Evaluating Coordination Between Isolated Language Model Instances
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2609.19504
- **Authors/org:** Alexander Shirnin, Aleksey Kudelya
- **Focus area:** covert coordination between instances
- **What it is:** For Your Eyes Only: can a model embed a signal that an isolated instance of the same model detects, with no shared memory? Most models struggle once detectable signals must be avoided, but one frontier model stays near-perfect; models can also misdirect; coordination is weaker across architectures.
- **Why it matters for Justin's agents:** Same-model monitor/worker pairs can share covert channels; mixing model families in monitor roles reduces this.
- **Action signal:** `track`

### 9. Language-model groups overstate consensus when replaying human deliberation on a reasoning task
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2609.20543
- **Authors/org:** Tengfei Shao
- **Focus area:** multi-agent simulation fidelity
- **What it is:** Replaying 100 human Wason-task groups with matched LLM agent groups: agents almost always post while ~1/5 of humans never did, and agent groups are 34–44 pp more consensual in sensitivity analyses.
- **Why it matters for Justin's agents:** Multi-agent 'consensus' is not evidence of correctness; don't use agent agreement as a verifier.
- **Action signal:** `track`

### 11. GAVEL: Graph World Models for Verified and Efficient Long-Horizon LLM Task Planning
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2609.19315
- **Authors/org:** Ruiyang Wang, Hao-Lun Hsu, Swarajh Mehta, Jiwoo Kim, Zhihao Dou, Miroslav Pajic
- **Focus area:** plan verification / world model
- **What it is:** GAVEL verifies and repairs LLM plans against an explicit graph world model (object relations, preconditions/effects, beliefs over unobserved locations), reserving LLM replanning for semantic errors. On BEHAVIOR-1K with Qwen3-8B, single-task success 41.2%→91.8%, multi-task 19.9%→92.6%.
- **Why it matters for Justin's agents:** Embodied, but the pattern — check actions against an explicit state model before executing — maps to calendar/task state for a day-admin agent.
- **Action signal:** `track`

### 12. Tailored to you: longitudinal effects of personalising language models

- **Link:** https://arxiv.org/abs/2609.20077
- **Authors/org:** Canfer Akbulut, Justine Breuch, Arianna Manzini, Lujain Ibrahim, Matija Franklin, Roma Patel et al.
