# AI Research Digest — Tuesday, November 24, 2026

## TL;DR
- **MobileGrail** (try-now) — Run a small local guardrail model over each proposed GUI action, carrying a compact task state so it knows what the user actually authorized.
- **Autoresearch harness: context and skills** (try-now) — Store past attempts as separately retrievable records (fold, do not summarize) and periodically delete skills the agent never uses.
- **Which failure does an intervention repair?** (compare) — Classify an agent's failures (missing knowledge vs execution error) before adding a skill, a harness layer or a bigger model.
- **HyperHarness** (compare) — Generate a user-specific retrieval function from the user's history once, then reuse it, instead of stuffing the whole history into context.
- **When Tools Fail, Agents Fabricate** (try-now) — Check tool outputs for partial or faulted data before the agent uses them, and send a corrective instruction rather than a hard block.
- **Content-free state in agent security evals** (compare) — Rerun agent security evals with shuffled tool order and different seeds, and report that variance next to any attack success rate.
- **STUN-Bench** (compare) — Store usage-based tool experience in a separate index from tool descriptions so new tools still get retrieved.
- **Conartist** (compare) — Test your agent's audit step itself as an attack surface, including injections that look consistent with the user's task.
- **LM harnesses as compositional generalizers** (compare) — Have the harness split long tasks into sub-calls that each see a short, in-distribution context instead of the full transcript.
- **Memanto on DolphinBench** (compare) — Evaluate memory layers on tasks where the agent must infer what to recall for a tool call, not only on explicit QA.
- **DMC-5** (try-now) — Keep the full trajectory append-only so a compressor can reuse its cache, and give the acting model only recent turns plus a summary that preserves tool-critical state.
- **MetaSkill** (compare) — Add a small library of reusable problem-solving methods that decide which skills to call and when to switch approach.
- **AdaptiveVPI** (compare) — Evaluate web-agent defenses with attackers who adapt to the defense, and check link destinations, not only screenshots.
- **NightWatch** (compare) — Pair a GUI agent with a small model that watches the screen continuously and flags changes before an action executes.
- **Apsis** (compare) — Statically check agent workflow graphs for missing required inputs and unsafe shared-state merges before deploying them.
- **Tool-call smuggling** (try-now) — Parse each tool call once, keep only fields in the approved schema, and pass that exact object to the executor sealed with its call ID.
- **SchemaCaps** (try-now) — Require re-approval whenever an approved tool's input schema widens, not only when it breaks compatibility.
- **IntentFlow** (compare) — Check recipient, endpoint and file arguments against what the user asked for, not only against where the value came from.
- **MMMem** (compare) — After each completed task, write a short experience record (context, conclusion, source links) into memory for later retrieval.
- **DoppelVet** (compare) — Before saving a self-written memory or skill, replay the agent with and without it and compare behavior.
- **PULSE** (compare) — Maintain an explicit time-stamped state of open loops and owners, and reconcile it across sources, instead of retrieving raw messages per question.
- **Consumer-time validity** (compare) — Bind each deferred approval to the target's revision and re-check it right before the action executes.
- **Composing distilled memory and retrieval policies** (compare) — Train separate small models for writing memories and for retrieving them, and test them together before deploying.
- **ContextFact** (try-now) — Store each remembered fact with its surrounding turns and maintain a separate per-entity profile linked back to the source dialogue.
- **Cumulative Consent Ledger** (try-now) — In approval prompts, show where the data in the outgoing artifact came from and whether any of it was marked private.
- **REMORA** (compare) — Keep provenance on every captured memory and have the assistant abstain when no stored record supports the answer.
- **AutoPILOT** (compare) — Let the agent emit short macros or small controllers for routine UI sequences instead of one model call per click.
- **Conversation-history integrity** (compare) — Sign or authenticate stored conversation turns and keep tool or retrieved content in a separate channel from user instructions.
- **Notary-gated retrospective loop** (compare) — Attach a held-out test to every rule an agent adds to its instruction file and remove rules that show no effect.
- **Detection gap in self-improving agents** (compare) — Monitor agent-written programs with checks derived from normal-run records rather than relying on checks the agent wrote.
