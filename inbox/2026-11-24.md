## News and changelogs
- **Anthropic API release notes:** Claude Opus 4.5 (`claude-opus-4-5-20251101`, `claude-opus-4-5`) deprecated, retirement on the Claude API scheduled for January 22, 2027; migrate to Claude Opus 5.5 — any agent pinned to Opus 4.5 needs a model bump. [link](https://platform.claude.com/docs/en/release-notes/overview#claude-opus-4-5-deprecation)
- **Anthropic API release notes:** Enterprise Frontier Safeguards (EFS) in beta on Claude Platform, Claude Platform on AWS and Claude Models on Google Cloud; it is Zero Data Retention for eligible organizations using the most capable models — a data-rules notice relevant to privacy posture of agent apps. [link](https://platform.claude.com/docs/en/release-notes/overview#enterprise-frontier-safeguards)
- **Anthropic API release notes:** two new organization webhook event types in beta, `external_storage.failed` and `external_storage.recovered`, for customer-owned storage bucket health checks — useful if agents persist data to your own bucket. [link](https://platform.claude.com/docs/en/release-notes/overview#storage-webhook-events)
- **Claude Code:** v2.1.331 adds Code Mode in terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and Claude Platform on AWS; `oidc.groups_jsonpath` for the Claude apps gateway; an API connectivity section in `claude doctor`; and `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION` for proxies that cut compressed responses. [link](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)
- **Graphiti:** mcp-v1.1.4 isolates groups for MCP tools (a UUID from another group errors instead of reading or changing data) and requires graphiti-core>=0.32.0 — tighter multi-tenant memory safety for an MCP memory server. [link](https://github.com/getzep/graphiti/releases/tag/mcp-v1.1.4)
- **OpenAI news:** OpenAI and Cisco introduce Shirudo, an open-source runtime for Linux that helps teams protect running systems while they roll out patches — little direct agent-platform angle. [link](https://openai.com/index/introducing-shirudo)
- **OpenAI news:** Connected intelligence for in-house legal, a video discussion on connecting business context and building reusable workflows — no direct agent-platform angle. [link](https://openai.com/business/learn/connected-intelligence-for-in-house-legal)
- **Vercel changelog:** AI Gateway now runs canary ZDR audits — zero-data-retention verification relevant to routing agent traffic. [link](https://vercel.com/changelog/ai-gateway-now-runs-canary-zdr-audits)
- **Vercel changelog:** AI Gateway providers can be chosen by headquarters country — a routing/data-residency control. [link](https://vercel.com/changelog/choose-ai-gateway-providers-by-headquarters-country)
