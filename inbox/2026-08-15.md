## Items

### 1. From LLM Inference to Agentic Workloads (AgentSysBench)
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2608.15127
- **Authors / org:** Chaokun Chang / Yukun Zhou / Kaihua Fu / Dakai An / Tianyu Feng / Hanfeng Lu / Sheng Yao / Pu Guo / Yinghao Yu / Yizhou Shan / Bo Li / Binhang Yuan / Wei Wang
- **Focus area:** Local / serving systems for agents
- **What it is:** Ten-application benchmark + instrumentation suite arguing that agentic serving is not "LLM inference with extra steps." Six properties from controlled deployments and production traces: (1) execution is heavyweight and stateful — **non-LLM components dominate latency in 5 of 10 apps**, sandbox working-set memory peaks at **28 GB per session**; (2) GPU-inference / memory-retrieval / CPU-sandbox affinities, task latencies diverge by up to **32×**; (3) bottlenecks shift across requests, models, deployments; (4) production sessions sit idle minutes-to-hours between steps; (5) a control-plane tax (auxiliary LLM calls + tool-schema/observation context) crowds out productive compute; (6) heavy cross-request redundancy in search/web fetches. Four design explorations: task-aware serving **−29–40% latency**, communication-aware placement up to **4.5×**, state offloading **4.6×** less memory, tool-result caching removes **35.2%** of redundant searches and **19.3%** of aggregate search latency. Submitted Aug 15; abs verified this run.
- **Why it matters for Justin's agents:** The 28 GB sandbox peak is the 64 GB unified-memory number of the week — a "small" local model plus a real coding/browser sandbox can eat half the machine before weights. Operational rules that fall out of the paper without a new trainer: (a) cache tool results across Mitamaton / Claude Code turns (search, web, calendar reads), (b) offload idle session state out of RAM between steps, (c) do not size the local server as if it were chatbot inference. The control-plane tax is why stuffing every MCP schema into the prompt feels slow even when the model is small.
- **Action signal:** `try-now` on tool-result caching + idle-state offload; `compare` before changing vLLM / MLX serving flags.
