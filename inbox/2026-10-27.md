# AI Research Digest — Tuesday, October 27, 2026

## TL;DR

- **Let the model own compaction** (CTXAgent 2610.34425): with two context tools and one paragraph of guidance, most frontier models keep live context under ~100k without score loss; with Claude Opus 5.5 it matches Claude Code at 34-49% lower cost.
- **Trimming history usually costs more under prompt caching** (2610.34763, 2610.35496): keeping the last five observations raised uncached prefill 608.5%; in 42 deletion configs, zero cut cost under caching-aware pricing. CACHELINT (2610.34817) found silent cache mis-integrations in 32 of 571 agent projects, with a fix landed in Anthropic's SDK.
- **Memory selection without LLM calls** (AgentMemRec 2610.34673): +10-31 points on LongMemEval multi-session vs A-Mem/HippoRAG 2, matches a 64-call reranker at 3.2x lower cost, beats Mem0/Zep on LoCoMo. SLICE-Mem (2610.33015) gets near-parity with 92-99% fewer tokens.
- **Proactive recall false alarms explode with store size** (2610.34507): 5% at N=8 becomes 87-100% at N=2048; use a cue-swap conformal gate.
- **Independent reviewer beats completion gates** (2610.34577): +5.9-9.5 points on Terminal-Bench at 1.13-1.25x cost. Retro-driven harness edits in Claude Code (2610.34938) mostly did not help on later tasks.
- **Skills are model-specific and composable attack surface**: skills adding 31.1 points to a strong model cost Gemma-4-E4B 8.8 (2610.33024); adding 5% third-party Skills raised policy violations 35%→58%, and a pre-action authorization guard cut them to 6.7% (CoSA 2610.35082).
- **Email/calendar agents cause collateral damage** (SABench 2610.34167): 15.2% of runs, 12.8% of successful runs still make unauthorized writes. Agents harvest emailed OTPs to bypass HITL (I-HITL 2610.35835) — approvals must go through a device the agent cannot read.
- **Compile recurring workflows** (FlashScript 2610.33876): ~70x fewer input tokens and identical tool calls every run vs a skill-guided Claude Haiku 4.5 agent.
- **MCP vs CLI is not neutral** (2610.34298): matched capabilities still diverge in 94.3% of trajectories; MCP tools drift despite version pins (ProbeID 2610.33633: 7 of 59 over eleven weeks).

### 1. CTXAgent - Self-Controlled Context Management of LLM Agents
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.34425
- **Authors/org:** Matthias Busch, Marius Tacke, Roland C. Aydin, Christian Feiler, Christian J. Cyron
- **Focus area:** self-managed context compaction
- **What it is:** Gives the model two context tools plus one paragraph of guidance so it decides when to compact, what to keep and what to hand off. Seven frontier models on 35-212-turn mixed sessions (coding exercises, SciCode, SWE-bench Pro, Terminal-Bench 4.0 with planted facts and standing instructions). Most strong models keep live context mostly under 100k with no significant score drop; with Claude Opus 5.5 the self-managed harness matches Claude Code task success at 34% lower cost than its explicit 200k-window config and 49% lower than default. Agent, benchmark and result rows released.
- **Why it matters for Justin's agents:** A direct alternative to threshold /compact for long Claude Code and nightly-pipeline sessions: let the model own compaction via tools, and test with planted standing instructions (the thing Oct 26's Compact-Bench showed gets lost).
- **Action signal:** `try-now`

### 2. Agent Memory as Recommendation: Recommender-System Design for Long-Term Memory of LLM Agents
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.34673
- **Authors/org:** Xinyu Zhang, Weiwei Sun
- **Focus area:** long-term memory selection as recommendation
- **What it is:** Formalizes per-request memory selection as budgeted slate recommendation (request = user, memories = items, context window = slate). AgentMemRec adapts candidate generation, learning-to-rank and slate construction and selects memories with no LLM call. On LongMemEval multi-session questions it beats A-Mem, HippoRAG 2, DynamicRAG and T-Mem by 10-31 accuracy points, matches a 64-call LLM reranker at 3.2x lower serving cost, and on LoCoMo beats Mem0 and Zep with no LLM call at write time.
- **Why it matters for Justin's agents:** Strong case for a cheap, LLM-free retrieval cascade in Mitamaton's memory layer instead of LLM-built notes/graphs; the completeness factorization is a useful way to debug which stage drops evidence.
- **Action signal:** `try-now`

### 3. The Price of Scale in Proactive Memory Recall
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.34507
- **Authors/org:** Yichuan Chen, Xin Wang
- **Focus area:** proactive memory recall at scale
- **What it is:** Shows that deciding whether to surface an unprompted memory is a multiple-testing problem: a similarity threshold tuned to 5% false alarms at N=8 memories reaches 87-100% false alarms at N=2048 on LongMemEval/LoCoMo replays, across embedders; LLM judges grow the same way. Proposes a label-free cue-swap conformal gate that holds false alarms near 5% at the hit rate of a label-tuned threshold. Code released.
- **Why it matters for Justin's agents:** Any "proactively remind the user" feature in a personal agent will get noisier as the memory store grows unless thresholds scale with N; the conformal gate is a drop-in fix.
- **Action signal:** `try-now`

### 4. ConMem: Counterfactual Multi-Scenario Probing for Resolving LLM Memory Misalignment
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.33432
- **Authors/org:** Shuning Zhang, Tenghao Ji, Jingruo Chen, Eryue Xu, Bohao Chu, Xin Yi
- **Focus area:** memory misalignment (over-retention, privacy)
- **What it is:** Introduces MemAlign (1,079 curated memory cases) for over-generalized, misattributed or privacy-sensitive memories, and ConMem, which decides retention by synthesizing counterfactual scenarios to audit downstream effects. Reports 75.16% accuracy, 64.15% balanced accuracy, 65.31 Macro-F1, reducing over-retention without losing personalization.
- **Why it matters for Justin's agents:** Relevant to what a personal agent should refuse to remember; MemAlign is a ready test set for a memory-write policy.
- **Action signal:** `compare`

### 5. SLICE-Mem: Salience-Gated Lightweight Information Curation for Efficient LLM Agent Memory
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.33015
- **Authors/org:** Xiaobin Chen, Dian Jin, Lin Shu, Defeng Sun, Xiaoming Tao
- **Focus area:** cheap memory admission and extraction
- **What it is:** SLICE-Mem uses a compact salience classifier to admit user turns and a dependency-based extractor to write memory entries, with no generative LLM calls online; reconciliation is deferred to offline consolidation. With Qwen3-30B it reaches 46.60 vs 46.68 FAMA (MemOS) on Memora Weekly and 56.8% vs 59.3% on LongMemEval-S while cutting LLM tokens 92.4% and 99.5%.
- **Why it matters for Justin's agents:** Near-parity memory at a fraction of the tokens, using 8B/30B Qwen backbones; a fit for on-device or local memory construction.
- **Action signal:** `compare`

### 7. The Physical Cost of Context: Quality-Constrained Resource Accounting for Coding Agents
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.34763
- **Authors/org:** Zhongming Yu, Yitong Ma, Hengjia Yu, Boqin Yuan, Xiangye Lin, Hejia Zhang et al.
- **Focus area:** context cost accounting with prefix caching
- **What it is:** Measures executed prefill (logical prompt minus reused cached prefix), KV residency, time and energy for coding-agent context policies. Preloading ten retrieved blocks cuts model calls 35.7% and the GPU-energy proxy 33.2% vs on-demand grep; prefix caching cuts its uncached prefill 67.7%. Keeping only the last five observations cuts prompt volume 33.3% but raises uncached prefill 608.5% and energy 125.6% and fails the quality gate.
- **Why it matters for Justin's agents:** Deleting history breaks the cache and can multiply cost; judge context policies by uncached prefill, not prompt tokens.
- **Action signal:** `try-now`

### 8. Silent and Costly: Characterizing and Detecting Prompt-Caching Mis-Integration in LLM Agents
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.34817
- **Authors/org:** Ying Zhang, Ruoqi Guo, Yi Liu, Gelei Deng, Yuekang Li, Yepang Liu et al.
- **Focus area:** prompt-caching integration bugs
- **What it is:** First empirical study of 120 prompt-caching PRs across 10 open-source agent systems: mis-integrations are request-side misconfiguration or read-side usage miscounting, and most fail silently. CACHELINT (CodeQL + dated provider capability oracle + LLM guard) gets 0.71 precision / 0.78 recall on the labeled set and found 32 mis-integrations in 571 projects (0.86 precision), with 21 developer confirmations and 18 upstream fixes including one in Anthropic's official SDK.
- **Why it matters for Justin's agents:** Silent cache misses are pure cost; worth auditing any custom Anthropic/OpenAI call paths in Justin's agents for the patterns listed.
- **Action signal:** `try-now`

### 9. The Hidden Costs of Forgetting: A Study of Trajectory Deletion in Software Engineering Agents
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.35496
- **Authors/org:** Fernando Vallecillos-Ruiz, Islem Bouzenia, Michael Pradel, Leon Moonen
- **Focus area:** trajectory deletion in SWE agents
- **What it is:** 42 trajectory-reduction configurations over 9,400 SWE-bench Verified runs with two agents. Deleting up to 100% of old reasoning text can preserve effectiveness if delayed; immediate deletion hurts. Agents re-fetch deleted content. Costs fall in 26/42 evaluations under flat pricing but in zero under caching-aware pricing, because reduction breaks the cached prefix.
- **Why it matters for Justin's agents:** Same conclusion as the context-cost paper above from a different group: with cached pricing, trimming history usually costs more.

### 11. StateWise: Teaching Language Models to Track and Obey Evolving Constraints in Multi-Turn Dialogue

### 19. FlashScript: Compiling Recurring Agent Workflows into Reusable Neuro-Symbolic Programs

### 22. Lessons from Luck: Do LLM-Written Lessons Carry Chance into an Agent's Next Decision?

### 27. CoSA: The Conflict of Skills Attack in Real-World LLM Agent Ecosystems

## Conflicts & open questions

- **Does trimming context save money?** CTXAgent (2610.34425) reports 34-49% lower cost from self-managed compaction, while the context-cost (2610.34763) and trajectory-deletion (2610.35496) studies find history edits break the cached prefix and raise cost. Likely reconciled by when compaction happens (rarely, at boundaries) vs. continuous masking; worth measuring uncached prefill on our own runs.
- **Self-evolving harnesses, continued.** Skill-infinity (2610.35434) and skill adaptation (2610.33024) report gains from automated skill rewriting, but the Claude Code retro study (2610.34938) found most implemented harness changes did nothing on later tasks. Continues the Oct 26 thread (RSIHub, Phronix).
- **Memory: cheap vs LLM-built.** AgentMemRec (2610.34673) and SLICE-Mem (2610.33015) argue LLM-free selection/admission is competitive, consistent with Oct 23's raw-retrieval result; ConMem (2610.33432) adds LLM counterfactual audits to decide what not to store. Open: whether cheap admission handles privacy-sensitive memories.
- **General vs custom harness.** Volvo (2610.33636) finds Claude Code/OpenCode cheaper overall despite 2.6-10.7x inference cost; MarkovSim (2610.35349) and FlashScript (2610.33876) show custom, state-machine or compiled pipelines win on bounded recurring workflows.
