## Conflicts & open questions

- **Self-evolving harnesses vs skill trust:** Turbo Harness / Self-Evolving Harness / MILO push autonomous harness mutation, while Can Agents Trust Their Skills? and ActionGuard / Pretext / Skill Poisoning show skill/harness surfaces as attack and trust-chain failures.
- **Persistent memory help vs harm:** TAGGRAPH / RefCon / Galahad / GUI Agent Memory treat persistence as capability; When Correct Memory Goes Wrong and False Memory in Autonomous Agents show stored memory as a failure and attack surface.
- **Voice/mobile personal agents maturity:** AgBench, Talk2Agent, VAmoS, and Richard all target personal/voice/mobile agents, but benchmarks disagree on whether simulation fidelity or device constraints are the binding limit.
- **Plan-Act consistency vs long-horizon reliability:** Consistent Plan-Act and Staying on Task both require fidelity over long horizons; WorkGenesis and PhantomEnvironments imply environment/curriculum design may dominate planner tweaks.
- **Computer-use speed vs memory:** cua-speedrun and ComputerSD optimize CUA feedback/speed; Action Conditioned Bisimulation and OSWorld-Science stress memory and scientific-tool competence — speed gains may trade off state retention.
- **Marketplace skills vs closed harnesses:** SkillSeek assumes large skill marketplaces; Mid-Harness / Composing Harnesses / How Much Harness assume a controlled harness surface — Mitamaton needs a stance on open vs curated skills.
