## News and changelogs
- **Claude Code:** v2.1.302 adds `CLAUDE_CODE_AUTO_MODE_MODEL` to pick the model for the client-side auto-mode classifier, an `Idle compaction` toggle in `/config`, and a notice that standalone Claude Design (claude.ai/design) closes December 14, 2026; fixes include a "Prompt is too long" error when stopping during compaction, Read refusing image sources over 128 MB, and a prompt-cache miss when a mid-session tool is reloaded via ToolSearch or after compaction — directly touches compaction and cache behavior in a Claude Code harness. [link](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)
- **Apple Developer:** App Review Guidelines revised — 1.2 clarified (safeguards for user content, Code of Conduct violations), new 2.3.14 on creative assets, new 2.5.19 on hidden, dormant or undocumented features (formerly under 2.3.1), 3.1.1(a) music-streaming entitlement folded into the StoreKit External Purchase Link entitlement, and 5 clarified on removal for trafficking/child exploitation — 2.5.19 matters for any iOS agent app whose capabilities change after review (e.g. server-side tool or model switches). [link](https://developer.apple.com/news/?id=92th7e5i)
- **Apple Developer:** Apple is strengthening the guidelines against nonconsensual intimate imagery ("nudification" apps) and bait-and-switch apps that reveal harmful capabilities only after approval; UGC apps must filter objectionable content, offer reporting and blocking — an app-rules notice relevant to any generative or agent feature in an iOS app. [link](https://developer.apple.com/news/?id=vvzx6cul)
- **OpenAI API changelog:** prompt-to-voice released for all API customers (create a custom voice from a text description and reuse it in GPT-Live sessions; creating the voice is free, speech uses normal GPT-Live billing), plus nine new natural GPT-Live voices across German, French, Hindi, Japanese and Korean — relevant to voice-first agent front ends. [link](https://developers.openai.com/api/docs/changelog)
- **Vercel:** two new AI Gateway model listings — Perplexity's Decider V1.2 models, and Reflection AI's Beam (free on the gateway) — more routing options behind one gateway API. [Decider V1.2](https://vercel.com/changelog/perplexity-decider-v1-2-models-now-available-on-ai-gateway) · [Beam](https://vercel.com/changelog/reflection-ai-beam-now-available-on-ai-gateway-for-free)
- **Composio changelog:** Python `composio` 0.28.0, `@composio/core` / `@composio/slim` 0.25.0 and CLI 0.4.5 add session tool approvals — set `requireApproval` on session toolkit, tool or tag filters, catch the input-required error, show its input requests, and repeat the call with the responses and request state (works for tool and meta-tool execution); also an MCP approval fallback, Python 3.15 support, and CLI mutations no longer retried — a ready-made human-approval loop for tool calls in an agent. [link](https://docs.composio.dev/docs/changelog/2026/10/16)
