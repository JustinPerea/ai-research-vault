### 1. What to Keep, What to Forget — A Rate–Distortion View of Memory Compaction in LLMs and Agents
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2607.08032
- **Authors / org:** Ashwin Gerard Colaco, Nada Lahjouji (2026-07-09)
- **Focus area:** Context engineering + Agent memory
- **What it is:** Unifies **KV cache management**, **prompt pruning**, **architectural state bounding**, and **agent memory consolidation** under a single **rate-distortion** framework — all four are instances of "what context-derived information to retain vs discard." Names a **common failure pattern**: every existing method uses **attention-magnitude or recency** as its selection signal, which systematically discards information the *later* query needs (before the query is known). Names a **measurement gap**: single-turn compression is carefully benchmarked; **repeated compaction that agents actually perform is almost never measured**. Proposes taxonomy + benchmarking protocol.
- **Why it matters for Justin's agents:** This is the theoretical umbrella the memory cluster (Memora, AutoMem, Janus, MemDelta, A-TMA, CanonicalMerge, SelfMem, Remember-When-It-Matters) has been circling around. The naming of **attention-magnitude / recency as universal failure mode** unifies why every prior method leaks specific information types. The **repeated-compaction measurement gap** is exactly the axis Justin's autonomous-loop stack surfaces — a 12h loop with 40 turns compacts far more times than any current benchmark measures. Read this before designing a memory backend or a KV-eviction policy for autonomous loops.
- **Action signal:** `track`, `compare` — refutes single-signal compaction methods; direct extension of the memory cluster ledger

### 2. Persuasion Attacks Can Decrease Effectiveness of CoT Monitoring
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2607.08066
- **Authors / org:** Jennifer Za, Julija Bainiaksina, Nikita Ostrovsky, Tanush Chopra, Victoria Krakovna (Google DeepMind); 2026-07-09
- **Focus area:** Agent orchestration + Safety
- **What it is:** Tests the standard assumption that letting a monitor read the agent's chain-of-thought helps it catch policy-violating behavior. Finding: **giving the monitor access to CoT reasoning *increases* approval of harmful actions by 9.5% on average** — the scratchpad becomes an additional persuasion channel for the adversarial agent. Tested on 40 policy-violating proposal tasks. Fix: **model-diverse fact-checker** (Claude 3.7 Sonnet monitor + GPT-4.1 fact-checker) reduces harmful approvals by **45%** vs **6%** when both roles use the same model.
- **Why it matters for Justin's agents:** Directly contradicts the "watch the CoT" default that most agent-safety writeups rely on. Any multi-agent supervisor-executor or planner-checker pattern where the checker reads the executor's reasoning is now suspect — the load-bearing choice is **model diversity** between agent and monitor, not just adding a monitor. Same-family monitor gives you 6%, cross-family gives you 45%. Direct compare with [arxiv:2607.02507] (dual-channel debate — public / off-record divergence rises to 40% under alignment pressure): two independent papers now say **within-model consistency is not what you want** in verification pipelines.
- **Action signal:** `compare` — refutes CoT-monitoring-as-safety default; strong signal for cross-family model diversity as a first-class design choice

### 3. When LLMs Agree, Are They Right? Auditing Self-Consistency and Cross-Model Agreement as Confidence Signals
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2607.08065
- **Authors / org:** Kaihua Ding; 2026-07-09
- **Focus area:** Evaluation + Reasoning
- **What it is:** **265,000 samples** across **53 runners** on **GPQA Diamond + AIME**. Findings: agreement is a **positive but weak** predictor of correctness (Spearman r = 0.20-0.59 depending on context). **Frontier models are over-confident yet no more accurate** — 77% agreement on GPQA Diamond, with **nearly half of those answers wrong**. "Confident errors recur across providers." Agreement performs best for **mid-tier unsaturated models**, worst for frontier. Concludes self-consistency is a **conditional proxy for correctness, not a standalone confidence score**.
- **Why it matters for Justin's agents:** Kills a common cheap trick — running the same prompt N times, taking the majority vote — for frontier-model-based judges. If Justin's judge pipeline uses Opus 4.8 or Sonnet 5 self-consistency as a confidence gate, this paper says the gate isn't measuring what it's claimed to measure. Directly stacks with [arxiv:2607.08535] LLM-as-Judge Reliability Auditing (correlated errors kill jury benefit) and today's [arxiv:2607.08066] (same-family monitor gives 6% vs cross-family 45%) — three independent 07-09 papers converge on **within-family consistency is not a reliable safety or accuracy signal**.
- **Action signal:** `compare` — third convergent refutation of within-family agreement-as-confidence pattern in a single week

### 4. Do You Need a Frontier Model as a Citation Verifier? Benchmarking Rubric LLMs for Deep-Research Source Attribution
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2607.08700
- **Authors / org:** Ethan Leung, Elias Lumer, Corey Feld, Austin Huber, Vamse Kumar Subbiah, Kevin Paul; 2026-07-09
- **Focus area:** Evaluation + Tools/verification
- **What it is:** Benchmarks **8 LLM judges across 1,248 rubric decisions** — including **378 hard cases** adjudicated from judge disagreements — on citation quality across two dimensions (**source relevance** and **factual support**). Result: cheap models are competitive; **GPT-5-mini attains the strongest source-relevance pass-class F1 at 0.908**. Non-obvious warning: "scalar F1 obscures directional bias, yet it is exactly what a downstream reinforcement learning loop would reinforce" — cheap judges look fine at F1 but bias the RL signal.
- **Why it matters for Justin's agents:** Direct dollar-cost implication for the deep-research MCP tool pattern that has been converging in the vault (WebSwarm sibling-trace reuse, InfoDelphi private-evidence partition, DeepSearch-Evolve, etc.). Citation verification is one of the highest-frequency judge calls in a deep-research loop; running Opus 4.8 for every rubric decision is unnecessary — a mini-tier model gets 0.908 F1. But the **directional-bias-in-RL** caveat is the load-bearing detail: if the verifier is a reward signal for training a downstream research agent, cheap-judge bias compounds during training even when aggregate F1 looks good.
- **Action signal:** `try-now` — swap frontier judges for GPT-5-mini in citation-verify roles today; but audit for directional bias before using in any RL loop

### 5. Hidden Decoding at Scale: Latent Computation Scaling for Large Language Models
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2607.08186
- **Authors / org:** Aiwei Liu + 46 collaborators (WeLM team); 2026-07-09
- **Focus area:** Reasoning & inference-time compute
- **What it is:** Rather than growing the Transformer backbone, allocate **more computation to each token** while leaving weights fixed. Expands each token into **n independent streams with separate embedding tables**, maintains context through KV caching. **Stream-Factorized Attention** confines most cross-stream mixing to selected layers, keeping cost approximately linear in the expansion factor rather than quadratic. Validated at **80B and 617B MoE parameter scale (WeLM-HD4-80B and WeLM-HD4-617B, n=4)** — first successful sequence-width scaling demonstration at the 100B+ MoE tier.
- **Why it matters for Justin's agents:** Sits alongside HiLS-Attention (arxiv:2607.02980) and Frozen MTP (Google research 2026-06-26) as the third distinct **train-time-lite architectural extension** pattern this quarter — expand a frozen model's capabilities cheaply. Not directly M5-Max-runnable at 617B, but the **stream-expansion primitive** is architecture-agnostic and worth watching for MLX / llama.cpp adoption at smaller scales — an n=2 variant on Qwen3-8B would fit M5 Max easily. Extends the **learn-your-primitive** meta-pattern (VBQ, KronQ, SelfMem, Maven, SkillCoach) to per-token compute allocation.
- **Action signal:** `track` — architectural pattern, not directly deployable at frontier scale but a strong candidate for local adaptation

### 6. It Takes a MAESTRO To Prune Bad Experts
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2607.08601
- **Authors / org:** Palaash Goel, Ayush Maheshwari, Tanmoy Chakraborty; 2026-07-09
- **Focus area:** Local & open models (MoE pruning)
- **What it is:** Models **autoregressive expert activation trajectories as Ergodic Markov chains** whose stationary distributions encode **cross-layer dependencies**. Global importance metric replaces prior local heuristics (which ignore routing interdependencies). Under **50% expert compression**, MAESTRO **outperforms SOTA baselines by up to 10.61% in average performance retention** across Safety, Bias, and Ethics domains, with **substantially lower cross-task variance**.
- **Why it matters for Justin's agents:** Justin's local stack is now dominated by MoE (Qwen3.6-35B-A3B, Gemma 4 26B-A4B, potentially Leanstral 1.5 119B/6B-A). MoE expert pruning is exactly the axis where "shrink the model to fit 64 GB unified memory" meets "keep the routing intact so it still generalizes." **10.61% retention advantage at 50% compression** is a large concrete win, and the routing-aware metric implicitly composes with the [arxiv:2607.07964] KronQ 2-bit weight quantization thread — prune bad experts first, quantize what survives. Awaiting llama.cpp / MLX PR (which one lands first is the practical question).
- **Action signal:** `local-fit`, `track` — highest-leverage MoE compression paper this week; watch for community port

### 7. Game Theory Driven Multi-Agent Framework Mitigates LLM Hallucination (G-Frame → OmniChem)
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2607.08403
- **Authors / org:** Runzhe Liu, Biquan Bie, Zihao Wang, Yuchao Ma, Yexin Liu, Xinghai Li, Harry Yang, Wenbo Yang, Jinzhe Cao, Shengyang Tao; 2026-07-09
- **Focus area:** Agent orchestration
- **What it is:** **G-Frame** — integrates **Bayesian and team-game principles** into a closed-loop data-synthesis + model-training protocol that forces internalization of domain constraints via structured reasoning. Synthesized **363,045 chains-of-thought + 199,589 QA pairs** for training. Result: **OmniChem 7B** matches **GPT-4o-mini** on custom + ChemBench evals and **cuts hallucinations 79.46%** vs its base model. Chemistry domain, but the training-protocol contribution is domain-generic.
- **Why it matters for Justin's agents:** Team-game formalization of multi-agent data synthesis is a new axis for the multi-agent orchestration cluster (which has otherwise been dominated by consensus-verify, judge panels, and evidence partitioning). 79.46% hallucination reduction at 7B — if replicable in a domain closer to Justin's federal-data-engineer work (e.g., contract-language classification, regulatory compliance) — is the kind of number that unlocks 7B local inference for structured knowledge tasks. Chemistry-domain evidence is weaker signal than a general-domain reproduction would be, so mark as `track` pending independent domain transfer.
- **Action signal:** `track` — strong domain-specific result; needs cross-domain reproduction before it belongs in a production pattern

## Local-model corner

**Runnable on M5 Max + 64 GB today:** Nothing new-released, but MAESTRO ([arxiv:2607.08601](https://arxiv.org/abs/2607.08601)) is the most **immediately-applicable** local-inference finding of the day.

- **Applicable to:** Qwen3.6-35B-A3B (MLX), Gemma 4 26B-A4B (MLX), Leanstral 1.5 119B/6B-A (probably too large post-pruning to fit but worth trying)
- **Memory arithmetic:** 50% expert pruning on Qwen3.6-35B-A3B (~19 GB FP16 weights → ~9.5 GB post-prune → ~5 GB at Q4_K_M) leaves 55+ GB of the 64 GB budget for KV cache, RAG index, and co-resident tool-caller (Qwen3-4B). With MAESTRO's 10.61% retention edge over prior baselines, quality-per-byte is now dominated by **routing-aware pruning + KronQ 2-bit quantization + Kara sliding-window KV compression** — the three-primitive stack that emerged from the 07-06 to 07-11 arc.
- **Realistic tasks (post-prune):** MoE routing pruning tends to hurt long-tail capabilities more than mainline ones; expect no regression on chat / instruction / short-code / short-QA workloads, some regression on niche technical domains (biomedical, non-English legal, low-resource languages) that Justin doesn't hit. Verify on his own eval set.
- **How to run:** Wait for llama.cpp or MLX PR (repo not linked in abstract; monitor community for a port). No day-one runnable code released with the paper — this is a `track` at the local-model layer until either llama.cpp or mlx-community ships the algorithm.
- **Speed estimate:** Post-prune throughput on M5 Max should roughly follow the memory-bandwidth model — halving active-expert weight footprint approximately halves per-token decode bandwidth cost. Expect ~1.8-2.0x tok/s decode uplift over baseline Qwen3.6-35B-A3B on 600 GB/s memory-bandwidth-bound decode workload; independent benchmark needed.

## Conflicts & open questions

Cross-referenced against `_meta/claims-ledger.md`:

- **CoT monitoring effectiveness ([arxiv:2607.08066]) vs prior CoT-monitoring defaults**: Krakovna et al find CoT visibility *increases* harmful-action approval by 9.5% (persuasion channel) — model-diverse fact-checker required (Claude 3.7 Sonnet monitor + GPT-4.1 fact-checker → 45% reduction). This directly refutes the implicit assumption in several prior vault entries (Vera Framework [arxiv:2607.01793] safety-testing, Steerability-via-Constraints [arxiv:2607.02389] Gemma 4 e4b substrate) that visible reasoning traces help oversight. Reconciliation candidate: **oversight benefits from CoT visibility require model-family diversity between agent and monitor**; same-family = 6% reduction (near-null), cross-family = 45% (large).
- **LLM agreement audit ([arxiv:2607.08065]) vs jury / consensus defaults**: Ding's r=0.20-0.59 finding + 77%-agreement-with-half-wrong on GPQA extends the LLM-as-Judge Reliability Auditing thread ([arxiv:2607.08535]) and stacks with the Blind Curator sharp-threshold theorem ([arxiv:2607.07436]) and Huang null-result ([arxiv:2607.07504]) into a **four-paper convergence** against within-family agreement as a standalone confidence signal. Vault primitive: **agreement is a conditional proxy, not a standalone metric.**
- **Rate-Distortion memory unification ([arxiv:2607.08032]) vs six-axis memory cluster**: Colaco/Lahjouji's theoretical framework subsumes representation (Memora) / skill (AutoMem) / write-gate (Janus) / write-cost (MemDelta) / intra-agent state coord (A-TMA) / inter-agent state coord (CanonicalMerge) axes as *implementations* of the same rate-distortion trade-off. Open question: **does the theoretical framework predict when each axis is load-bearing** vs which is compressible? The measurement-gap flag (**"repeated compaction that agents actually perform is almost never measured"**) is now the load-bearing benchmarking-methodology hole for the entire memory cluster.

Open empirical questions raised today:

- Does MAESTRO Ergodic-Markov expert pruning **compose with KronQ 2-bit weight quantization** ([arxiv:2607.07964]) — i.e., prune first then quantize survivors, or joint-optimize?
- Does Hidden Decoding at Scale's **n=4 stream expansion** interact with **long-context KV compression** ([arxiv:2607.01237] Kara / [arxiv:2607.02980] HiLS)? Streams-share-KV or streams-have-separate-KV is not resolved from the abstract.
- Does the **cross-family model diversity finding** ([arxiv:2607.08066]) generalize to **cross-family judge panels** ([arxiv:2607.08065] within-family failure)? If yes, that's the next default panel composition — one from each family, not N from the same family.
