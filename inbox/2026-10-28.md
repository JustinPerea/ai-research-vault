### 1. Spine: Compiling Subtask Trees into Structured Context for Long-Horizon Coding Agents
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.37224
- **Authors/org:** Jiahong Xiang, Kunqiu Chen, Lingming Zhang, Yuqun Zhang
- **Focus area:** subtask-tree context compilation for coding agents
- **What it is:** Spine lets an agent declare explicit subtask boundaries (work scopes), runs nested subtasks inline and reserves delegation for independent parallel work. A persistent SpineTree records subtask relations, interactions, completion state and results; before each model call it compiles the tree into context just in time, keeping unfinished subtasks' interactions and replacing finished ones with their results while preserving prefix-cache reuse. SpineCodex (GPT-5.6 Sol) vs native Codex: +11.8% SWE-Milestone Score at 32.4% lower cost, +17.3% ProgramBench test-pass; matches Recursive Subagent at 73.7% lower cost. A Pi package gives +9.5-17.5% with Gemini 3.8 Flash and Qwen 3.8 27B.
- **Why it matters for Justin's agents:** Concrete answer to yesterday's compaction-vs-caching tension: summarize at subtask boundaries, keep the prefix stable. Directly portable to long Claude Code / nightly-pipeline sessions and works with an open 27B model.
- **Action signal:** `try-now`

### 2. Context Is a Pipeline, Not a Window: Information Attrition in LLM Agent Harnesses
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.36114
- **Authors/org:** Yuvraj Sehgal, Mahsa Panahandeh, Naser Ezzati-Jivan
- **Focus area:** tool-output truncation in agent harnesses
- **What it is:** Measures what a harness drops before the model sees it. In a kernel-trace RCA agent over 720 runs the largest prompt used 5.75% of the window, yet 3,827 of 11,189 tool results were cut by fixed-length JSON slicing, each becoming broken JSON; one field reached the model in 4.7% of calls. Models context as a five-stage pipeline; replaying 864 real results, the cut's cost shows up first as extra work (43% more tool calls, 2x compute, yield 0.61 to 0.31). Two of seven surveyed agent frameworks truncate the same unsafe way. Causality of the accuracy drop is left open.
- **Why it matters for Justin's agents:** Audit our MCP servers and harness wrappers for naive character-slicing of JSON tool results; truncate structurally (drop records, keep valid JSON, say what was cut).
- **Action signal:** `try-now`

### 3. Stratum: Repository Memory for Coding Agents Beyond the Context Window
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.36153
- **Authors/org:** Yuvraj Sehgal, Mahsa Panahandeh, Naser Ezzati-Jivan
- **Focus area:** persistent repository memory for coding agents
- **What it is:** Argues coding-agent amnesia is a memory-architecture problem, not context length: KV-cache storage costs 10^4-10^5x more bytes than indexed text; median bug fix touches two files (<10% of repo with imports); 47% of co-edited file pairs are structurally disconnected, so selection must be mined from history. Sketches Stratum, a tiered memory stored with the repo and served by page-safe tools that report what was returned, what remains and the cost. 1.7 ms median retrieval over 1M nodes; a fresh agent inheriting another model's session memory found the root-cause file in 21/24 trials vs 6/24 for retrieval-only, at 4.5x lower median token cost.
- **Why it matters for Justin's agents:** Validates a repo-resident, cross-model memory (notes that survive sessions and model swaps) and the 'page-safe tool' response contract for our own MCP tools.
- **Action signal:** `try-now`

### 4. Concordat: Typed Sessions for LLM Agents
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.37461
- **Authors/org:** Milad Sikaroudi
- **Focus area:** runtime-enforced tool protocols (typestate) for agents
- **What it is:** Concordat, an open-source Python library, treats an agent as a finite-state protocol: each turn the model only sees tools legal in the current state, out-of-protocol calls are rejected before side effects, human-reserved decisions can only be requested, and token/tool budgets split linearly across handoffs. Protocols are checked at definition; subclasses that could bypass the parent's protocol are rejected. On tau-bench airline (50 tasks) with customers pressuring to skip confirmation, the standard agent changed things without the required 'yes' in 13/50 (gpt-4.1) and 29/128 runs (Claude Haiku 5.5); Concordat made none, with no significant task-success change. tau-bench reward missed most violations.
- **Why it matters for Justin's agents:** Exactly the shape Mitamaton needs for confirm-before-write actions (calendar, email, payments): gate tools by state in code, not prompt text.
- **Action signal:** `try-now`
> _Promoted to [[Research/topics/agent-security]] on 2026-10-28_

### 5. CASEL: Consequence-Aware Selective Execution for Reliable Long-Horizon Tool-Using Agents
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.36570
- **Authors/org:** Yanyan Zhang, Fei Shen, Ting Yan, Hao Zhang
- **Focus area:** consequence-aware runtime gating of tool calls
- **What it is:** CASEL picks per tool call among direct execution, verification, sandboxing, clarification, approval and abstention by combining calibrated failure probability, state-dependent consequence, reversibility, ambiguity and evidence freshness. In simulation (20 seeds x 120k actions, same menu and compute), harmful-side-effect trajectories drop from 14.75% (uncertainty gate) to 7.02%; a failure-prob x consequence gate reaches 5.82% but sends 45% more actions to human approval; removing reversibility routing raises harm to 15.53%. Authors note intervention effectiveness is assumed, not measured.
- **Why it matters for Justin's agents:** Reversibility is the cheap signal that matters: route irreversible writes to approval and let reversible ones run. Pairs with Concordat as a policy layer.
- **Action signal:** `compare`

### 6. Log-To-Leak: Prompt Injection Attacks on Tool-Using LLM Agents via the Model Context Protocol
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.36108
- **Authors/org:** Yuepeng Hu, Chongyu Fan, Sirat Samyoun, Jian Du
- **Focus area:** MCP tool-description prompt injection (exfiltration)
- **What it is:** Log-To-Leak poisons MCP tool metadata so the agent makes an extra attacker-controlled 'logging' call after its final legitimate call, leaking the user query, server name, server response and agent response. Across 18 model-server pairs (5 MCP servers, 4 agents): 62.64-100% attack success, 76.55-95.64% logging accuracy, and 16 pairs change task completion by at most 6.63 points, so success hides the leak. Three defenses leave >55% residual ASR on GitHub MCP with GPT-4o; an instruction detector flags 85.53% of benign descriptions.
- **Why it matters for Justin's agents:** Task success is not a safety signal for third-party MCP servers; require host-side authorization for secondary/unrequested tool calls, especially after the task is done.
- **Action signal:** `try-now`
> _Promoted to [[Research/topics/agent-security]] on 2026-10-28_

### 7. Does Your Generalist Skill Optimizer Really Incentivize Agentic Tasks? Rethinking Skill Optimization via Bipartite Attribution
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.37201
- **Authors/org:** Jiawei Zhou, Bo Peng, Yuxuan Huang, Ming Zhang, Youbang Sun, Xiang Wang, Chaochao Lu
- **Focus area:** auditing automatic skill optimizers
- **What it is:** BiPA replays a skill optimizer's acceptance rule on candidates identical to the seed and logs each episode as a bipartite graph of turns and text read. ## Conflicts & open questions

- **Do self-improvement loops actually improve?** BiPA (2610.37201) finds automated skill optimizers' gains are mostly selection noise, while RuHarness (2610.36826), PCE (2610.36660), Trinity (2610.36077) and EMMA (2610.35966) report sizable gains from evolving harnesses/memory. The scaffold-evaluation paper (2610.37276) suggests the fix: calibrated eval cores and paired final comparisons. Continues the Oct 26-27 thread (Claude Code retro study).
- **Compaction vs caching, continued.** Spine (2610.37224) claims both lower cost and prefix-cache reuse by summarizing only at subtask completion, a concrete reconciliation of Oct 27's CTXAgent vs trajectory-deletion conflict.
- **Memory: more context vs less.** Obsolete-facts (2610.36308) shows bigger retrieval budgets hurt; CrossProfile (2610.37624) finds full transcripts worse than no notes; Stratum (2610.36153) argues for selection mined from history. All point to curation at write time over larger reads.
- **Harness vs model.** kw-bench (2610.36405) says lab harnesses fail off their home models, while AgentBaton (2610.35959) shows mid-task model handoffs work within one harness — open question whether handing a Claude Code session to a cheaper non-Claude model hits kw-bench's 'inertia' failure.
