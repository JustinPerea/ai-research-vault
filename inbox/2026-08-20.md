## Items

### 1. Agentic Search — Mistral
- **Source:** Mistral News
- **Link:** https://mistral.ai/news/agentic-search
- **Authors / org:** Mistral (product, Aug 20, 2026)
- **Focus area:** Retrieval / tools for document-heavy agents
- **What it is:** Multi-step retrieval loop over an existing index via five filesystem-shaped tools: `search`, `open`, `navigate`, `read`, `grep`. No model-specific fine-tune. FinanceBench (368 SEC filings, ~147 pages avg, 150 questions): search-only loop is the big lever (**+47.3pp** MM 3.5 / **+52.6pp** GLM-5.2, ~3× vs one-shot RAG, 26.7% → 86% in the headline). Navigation adds **+8.7 / +6.7pp** and *reduces* tokens (**−23.9% / −33.7%**) and latency (p90 **255s → 154s**, mean **108s → 71s**). OfficeQA Pro (696 Treasury Bulletins, 133 numeric questions): full loop GLM-5.2 **6.3% → 51.9% (+45.6pp)**; MM 3.5 **+27.1pp**. Same GLM-5.2 on Claude Code harness scores **41.4%** vs **51.9%** on the Mistral harness (**+10.5pp** harness effect). Ships via Search Toolkit + Libraries in Studio/Vibe; Search Starter App for a local index.
- **Why it matters for Justin's agents:** Mitamaton's vault / filings / table-heavy PDFs are exactly the OfficeQA Pro shape. Portable recipe: stop one-shot RAG; give the agent `search` + `open` + `grep` over the vault and let it navigate. The +10.5pp GLM-5.2 harness gap is another Writer-Harness-Effect data point — the retrieval loop is the product. Model-agnostic, so it can sit in front of Opus *or* local Qwen.
- **Action signal:** `try-now` — expose vault as search/open/grep MCP tools; measure vs current chunk RAG on a 10-doc personal set.

### 2. SPADE: Self-Play in Adaptive Synthetic Executable Environments
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.19197
- **Authors / org:** Bo Liu / Simon Yu / Yiding Jiang / Ao Qu / Andrew Zhao / Zichen Liu / Junsu Kim / Zijian Zhou / Seungone Kim / Tongzheng Ren / Mickel Liu / Hanfei Yu / Zhaorun Chen / Weiyan Shi / Paul Pu Liang / Luke Zettlemoyer / Yejin Choi / Natasha Jaques
- **Focus area:** Environment generation + self-play RL
- **What it is:** One LLM plays two roles: an Environment Designer that writes complete Gym-style `reset()`/`step()` environments as executable code, and a Reasoning Agent that solves them. Hint-based regret targets the edge of capability. Load-bearing ingredients: grounding the Designer on a pretraining-corpus sample, plus accumulated environment memory. At 30B: **+5.3** over the strongest fixed-environment baseline across eight held-out math/science/code/reasoning benches; tool-use **+5.7** BFCL-v4 multi-turn and **+13.9** ACEBench-Agent. Code: github.com/spade-rl/spade. Submitted Aug 19 (v2 Aug 24); abs verified.
- **Why it matters for Justin's agents:** The environment, not the next SFT mix, is the curriculum. EnvHarness (tomorrow, Google) wraps a *frozen* env; SPADE *writes* new ones. If Mitamaton ever needs a personal eval world (calendar + mail + files), SPADE is the "generate the world as code" recipe. Without Designer training + memory the paper reports the loop collapses — do not skip those two pieces.
- **Action signal:** `compare` — against EnvHarness / AgentMercury as the env-gen stack; not a weekend run.

### 3. FM-Bench: A Benchmark for Long-Horizon Management with Competing Agents
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.18423
- **Authors / org:** Tianyou Wang / Chongyang Gao / Kezhen Chen / Dong Chen / Yinghao He / Donghan Li / Wangcheng Xu / Hongjiu Zhang / Chi Li — AnalogyAI
- **Focus area:** Long-horizon personal / management agents
- **What it is:** An LLM agent runs a football club for **20 in-game years** through **26 tools** and ~**340–400 decision stops**. Deterministic engine, no LLM judge. Solo: 15 frontier models vs a frozen scripted world; Arena: the same models plus a scripted anchor in one shared world. All 15 models complete every horizon; scripted baselines die out. **claude-fable-5** tops solo mean and the Arena, where the title still rotates among ten models. Neither scale, price, nor vendor predicts the order; the order settles late. Token spend predicts nothing. Higher-scoring models cut slow-payoff investment near the end, keep cash invested, and open renewals early. Self-managed memory fails two opposite ways: an archive that only grows, or a plan rewritten every season. Code: github.com/Analogy-AI/fm-bench. Submitted Aug 19; abs verified.
- **Why it matters for Justin's agents:** Long-horizon day-admin *is* management (hidden info, cumulative consequences, competing objectives, memory curation), not bounded tool-calling. The notebook is the only cross-stop state — FM-Bench's two memory failure modes (append-only vs wholesale rewrite) are exactly the Mitamaton failure modes. Score models on managerial behavior, not tokens.
- **Action signal:** `compare` — steal the six-capability behavioral scorecard; do not train on football.

### 4. SkillGate: Training In-Policy Skill Selection in Long-Horizon Agents
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.18852
- **Authors / org:** Qingyao Li / Wenxiang Jiao / Shuai Shao / Kangning Zhang / Yuan Lu / Yi Guo / Weiwen Liu / Weinan Zhang / Yong Yu — SJTU
- **Focus area:** In-policy skill selection (credit assignment)
- **What it is:** Which skill to *read* is a mid-episode policy decision, but outcome-rewarded RL cannot teach it: **selector credit starvation** — skill-name tokens carry a vanishing share of sequence-level loss and inherit wrong-signed credit as trajectories lengthen. A correct choice is punished whenever later execution fails. SkillGate splits token support into two disjoint credit channels: outcome credit on execution tokens, action-local advantage on skill-naming tokens (positive only when the trajectory's single read is the correct one). On five agentic benches under a 16-candidate slate, a 9B policy goes **40.8% → 53.2%** trial success, well ahead of the identical budget on outcome reward alone; exposure to misleading candidates drops by two thirds and the agent reads fewer skills. Code: github.com/DeepExperience/SkillGate. Submitted Aug 19; abs verified.
- **Why it matters for Justin's agents:** WikiSkill evolves skill *content*; CaSKG routes via a *graph*; SkillGate says in-policy *selection* must be trained, not left to retrieval. If Claude Code / Mitamaton starts RL on skill use, outcome-only GRPO will starve the name tokens. Two-channel credit is the load-bearing primitive.
- **Action signal:** `compare` — against CaSKG retrieval and WikiSkill injection; do not outcome-RL a skill selector.

### 5. Bounded Agents: Delegation Security for Multi-Agent AI Systems
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.15888
- **Authors / org:** Xabier Muruaga (independent)
- **Focus area:** MCP / multi-agent authorization
- **What it is:** Agentic Principal Chain (APC): session-aware authorization with six checks, composition closure (individually permitted actions must not compose into a prohibited outcome), blast-radius monotonicity, decisions enforced *outside* the model. Compromised-model eval inserts the ground-truth attack call after the first legitimate tool call. AgentDojo exfil **75–100% → 0%** across four domains; all **544** InjecAgent data-stealing cases blocked; destruction **38.6% → 4.0%**, manipulation **90.5% → 12.1%**. Utility **−8.6 / −13.9pp** in two AgentDojo settings; p99 auth latency **0.24 ms** on an idle host. 3,154 instances. Code: github.com/xmuruaga/bounded-agents. Submitted Aug 16; HF Daily Aug 20; abs verified.
- **Why it matters for Justin's agents:** SARA [arxiv:2608.27146] is observation-authorization (tool output may induce but must not authorize). APC is *session composition* of individually permitted actions. Complementary: SARA taints arguments; APC closes the "each step was allowed" hole. p99 0.24 ms is cheap enough to wrap every Mitamaton side-effecting tool. Independent author — replicate on Claude / local Qwen before treating 0% ASR as a guarantee.
- **Action signal:** `compare` — composition closure on send/create/pay/share; pair with SARA, do not pick one.

## Conflicts & open questions
- **SkillGate vs WikiSkill / CaSKG.** WikiSkill evolves content and injects at eval; CaSKG calibrates retrieval edges; SkillGate says the *in-policy name decision* is untrained under outcome RL. Three layers. Collapsing them into "skills just work" is the misread.
- **APC vs SARA vs HarnessRisk (yesterday).** Four complementary MCP-security layers if you count SecOPD (Monday): config (HarnessRisk), observation-authorization (SARA), composition closure (APC), model-level token credit (SecOPD). No paper compares them on one AgentDojo run.
