### 1. Reglos: A Self-Evolving Personal Memory Agent with Recursive Self-Improvement
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2611.06049
- **Authors/org:** Sen Yang, Jiaduo Lin, Zehong Huang, Wen Liu
- **Focus area:** self-evolving personal memory + harness self-improvement
- **What it is:** Training-free personal memory agent: append-only per-user record where new preferences supersede old ones and facts can be forgotten; the harness improves by recursive self-improvement (a coding agent proposes patches from failure traces, a critic from a second model family screens for benchmark gaming), then a fixed evaluator gates further patches after the harness is frozen. Same backbone for all systems: beats Mem0, MemOS and EverOS, 61.3% PersonaMem-v2 / 84.0% LongMemEval-S with Qwen3.8-27B; 57.5% / 87.2% with GPT-5.6 Luna.
- **Why it matters for Justin's agents:** Directly the Mitamaton memory shape (append-only + supersede + forget), plus a concrete guard against overfit harness patches: cross-family critic and a frozen evaluator before accepting changes. Copy the patch-gating pattern for Claude Code harness edits.
- **Action signal:** `try-now`

### 2. SUMONE: A Simple and Efficient Summarizer for Plug-and-Play Agent Memory
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2611.06445
- **Authors/org:** Jizhe Zhang, Ang Li, Chenheng Zhang, Yisen Wang
- **Focus area:** task-agnostic learned context compaction
- **What it is:** SumOne is a standalone summarizer trained with GRPO on a task-agnostic reward: a frozen reconstructor must recover randomly masked parts of the original trajectory from the summary, plus a length penalty. No reference summaries or task execution needed. About 78% lower estimated inference cost on DeepSearchQA and 75% on SWE-bench Verified vs full context, with absolute decreases of 0.04; the same checkpoint transfers across downstream models and harnesses without fine-tuning.
- **Why it matters for Justin's agents:** A plug-in compactor for long-horizon runs that does not couple to one agent or task. Compare against current Claude Code-style compaction on cost vs accuracy; check refusal/safety behaviour too (see 2611.06380).

### 3. Tools Need Not Speak in Text: Latent Context Compression for Agents
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2611.06500
- **Authors/org:** Yuetong Liu, Zhehao Zhou, Yitong Zhang, Haorui Chen et al.
- **Focus area:** latent compression of tool observations
- **What it is:** Coca-Cola compresses tool observations into continuous latent tokens injected into the agent's input embedding space, trained with Action-Preserving Training that aligns next-action distributions under full vs compressed observations. Web-search agents on four QA benchmarks and two model families: 70.01-89.24% fewer tokens, 24.45-55.97% lower end-to-end runtime, with consistently better task performance. Code released.
- **Why it matters for Justin's agents:** Tool outputs are the main context bloat in MCP-heavy agents. Requires open weights (embedding-space injection), so relevant for the local-model path, not hosted APIs.

### 4. Route to Remember: Adaptive Memory Selection for LLM Agents
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2611.05636
- **Authors/org:** Zeyu Fang, Jun Yin, Yongsheng Mei, Xu Han et al.
- **Focus area:** weight memory vs text memory routing
- **What it is:** Makes weight memory competitive as a long-term factual store via on-policy self-distillation (OPSD): a context-free student is trained from the same model conditioned on the user's memory, plus a verify-then-regenerate router that sends each query to weight or text memory. On HaluMem, OPSD matches or beats full-context prompting and retrieval baselines while reading fewer tokens per query; includes a study of training recipes.

### 5. Agent Harness Awareness: Turning Verified Telemetry into Operational Control for Tool-Using Agents
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2611.05391
- **Authors/org:** Manu Agrawal, Shrey Nagpal
- **Focus area:** host telemetry fed to tool-choosing agents
- **What it is:** Names 'operational blindness': the harness knows tool health from monitors/traces but the model does not. The host supplies a small, fresh, verified state snapshot before consequential actions while keeping enforcement and dispatch authority. ToolRoute benchmark, 216 decisions across GPT-5.6 Sol, Claude Sonnet 5, Gemini 3.7 Flash: mean policy regret down 96.9% (4,252 ms to 131 ms), single-dispatch completion 69.4% to 95.8%. Live replication with OpenTelemetry spans and Toxiproxy faults: 9/9 vs 5/9 completions.
- **Why it matters for Justin's agents:** Cheap harness change: inject verified tool/MCP-server health into context before a tool call, keep the decision authority in the host. Fits an MCP gateway that already has traces.

### 7. Signed, Sealed, Leaked: Trust Beyond Signature for MCP Toolchains
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2611.06585
- **Authors/org:** Yichiet Aun, Mohammed A. Alhartomi, Jing Jie Tan, Waqas Nadeem et al.
- **Focus area:** MCP tool data exfiltration defence
- **What it is:** A legitimately signed MCP tool can still leak data to a policy-allowed destination; Meta's MCPGuard-Dynamic blocked direct exfiltration but failed against this attack in every trial. - **Why it matters for Justin's agents:** Signatures and allow-lists are not enough for third-party MCP servers. Per-call forked, data-scoped execution is a concrete design for a local MCP host.

### 13. The Harness Is the Model: Agent Scaffolding Changes a Fixed LLM's Compliance with Banking Conduct Rules, Unevenly Across Models

## Conflicts & open questions

- **Compression vs safety:** SumOne (2611.06445) and Coca-Cola (2611.06500) report big token/cost savings judged on task accuracy, but 2611.06380 shows encoder-based compression weakens refusal behaviour despite high fidelity. Neither compression paper reports refusal or safety checks.
- **Weight vs text memory:** Route to Remember (2611.05636) argues weight memory can match text retrieval on HaluMem; Reglos (2611.06049) wins with a training-free append-only text record. Different benchmarks; no head-to-head.
- **Do harness gains transfer?** HarnessFlow (2611.06254) and Reglos optimize harnesses with the model fixed; 2611.06116 finds the same harness moves one model from first to last place and leaves another unchanged. Optimized harnesses likely need re-search per model.
- **Reviewers help or hurt?** 2611.06116 finds a same-model compliance reviewer cut violations (9.6% to 6.4%) without more over-refusals, while 2611.05390 shows broad reviewer override corrupts correct proposals (Mistral replaced all 48) and 2611.05662 shows tool-using judges defer to a false cue. Reviewer value depends on model, interface and what context the reviewer sees.
- **Self-assessment:** PAYWORTHY (2611.05759) finds success forecasts near random unless the agent's limits are stated; ViBench 2.0 (2611.05620) finds per-plan pass rates (98%) far above full-product success (65%). Both caution against trusting agent self-reports of completion.
