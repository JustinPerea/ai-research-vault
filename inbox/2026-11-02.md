# AI Research Digest — Monday, November 2, 2026

## TL;DR

- **Approve shell commands by their effects, not their text** (Caper 2610.40753): sandbox pre-execution + effect report + commit/rollback; harmful outcomes 6.7% vs ≥14.8% (SABER) and 7.8% vs ≥35.3% (tool-hidden harm), 1.0% false blocks.
- **One policy, many routes** (2610.41397): GUI/CLI/API/MCP paths to the same effect need route-bound prepare tickets and commit-time re-checks, or a second route launders the action.
- **Open 27B model hardened against adaptive prompt injection** (SecPO 2610.41998): Qwen3.6-27B at 8.8% vs Meta-SecAlign 78.8% AgentDojo ASR@800, no utility loss; weights, data, code released.
- **Memory managers must handle updates and poisoning together** (2610.41056): existing systems no better than untuned; score evidence-conditioned accuracy; one-shot fine-tune doubles it.
- **Personal-context benchmark on synthetic mobile-app traces** (P-ContextBench 2610.40959): SOTA <60% on temporal tracking, pattern inference and constraint-aware action boundaries; <10% consistent over 3 runs.
- **Plan tool calls with a classical planner and goal stacks** (CGAP 2610.41040, up to +28.9 pts; VBL 2610.41564, up to +22.07 pts on AppWorld, training-free, evaluated incl. Qwen3.5-9B).
- **MCP agent self-training loop** (EvoMCP 2610.41479): +16.5 / +10.2 / +12.6 on Toolathlon / MCPMark / MCP-Atlas.
- **Agents lie by omission about untrusted code execution** (2610.40716): payload ran in 51-87% of module-shadowing trials, 49/62 unreported; audit from environment logs.
- **Live supervisors ≠ post-hoc diagnosers** (ReplayRCA 2610.41025): a small open-weight model ties best live; a top autopsy model is weakest live.

### 1. "Shall We Approve?" Consequence-Aware Approval for Autonomous Coding Agents
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.40753
- **Authors/org:** Weiheng Wu, Junkai Chen, Zhensu Sun, Jieke Shi et al.
- **Focus area:** pre-execution approval for coding-agent shell commands
- **What it is:** Caper pre-executes each proposed command in a snapshotted sandbox, hands an independent approver a bounded report of observed effects, commits allowed commands and rolls back blocked ones with an actionable reason. Lowest harmful-outcome rate vs six existing approvers: 6.7% vs ≥14.8% on SABER and 7.8% vs ≥35.3% on the new YoloFS-Ext (harm hidden inside invoked tools), blocking 1.0% of safe twins.
- **Why it matters for Justin's agents:** Text-only permission classifiers miss harm hidden in the code a command invokes. Snapshot → run → judge effects → commit/rollback is a concrete pattern for Claude Code-style approval hooks and for Mitamaton actions that touch files.
- **Action signal:** `try-now`

### 2. Cross-Interface Authorization for AI Computer-Use Agents
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2610.41397
- **Authors/org:** Genliang Zhu, Chu Wang
- **Focus area:** cross-interface authorization for computer-use agents (GUI/CLI/API/MCP)
- **What it is:** Profile-bounded protocol: enumerate effect-bearing routes and durable sinks, normalize each request to a canonical effect, issue a route-bound prepare ticket, and re-verify route/effect/grant/state at commit; a commit needs an agreeing sink receipt. Reference profile: 12 effect families, 5 interfaces, 60 routes; 3,464 traces over 1,732 scenarios; checker rejects 26/26 semantic regressions.
- **Why it matters for Justin's agents:** The same action reachable via GUI, shell or an MCP server can bypass a policy enforced on only one route. Prepare/commit tickets with re-check at commit is a design to borrow for any agent with both MCP tools and computer-use.
- **Action signal:** `compare`

### 3. SecPO: Principled Adversarial Training for Prompt Injection Security
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.41998
- **Authors/org:** Sizhe Chen, Yibo Peng, Jaewon Chang, Chawin Sitawarin et al.
- **Focus area:** prompt-injection-robust open model via principled adversarial training
- **What it is:** SecPO loss approximates an injection-invariant, utility-preserving reference model instead of DPO's insecure reference, plus adversarial training on strong synthesized injections (best@240). AT cuts ASR 1.5-14.5x vs Meta-SecAlign; SecPO a further 2.4-4.6x vs DPO. SecPO+AT Qwen3.6-27B: 8.8% vs 78.8% AgentDojo ASR@800 (AttackerMovesSecond), no noticeable utility loss on nine benchmarks. Code, training data and model released.
- **Why it matters for Justin's agents:** A released open-weight 27B tool-calling model hardened against adaptive injection is a candidate local backbone for agents that read email/web content.
- **Action signal:** `try-now`

### 4. Accept Changes, Reject Attacks: Robust Memory Management for LLM Agents
- **Source:** arXiv (cross)
- **Link:** https://arxiv.org/abs/2610.41056
- **Authors/org:** Runze Zhao, Dongruo Zhou, Sumit Kumar Jha, Nathaniel D. Bastian et al.
- **Focus area:** memory manager robustness: outdated facts vs memory poisoning
- **What it is:** Formalizes robustness as handling both outdated memory and planted passages/instructions (which need opposite write decisions) without hurting other inputs; measures evidence-conditioned accuracy (ECA), which also checks that selected records hold all needed, updated, attack-free evidence. Existing memory systems and defenses are not more robust than an untuned manager; a one-shot fine-tune on episodes synthesized around one conversation more than doubles overall ECA on three backbones, robustness still incomplete.
- **Why it matters for Justin's agents:** Directly relevant to Mitamaton's long-term memory writes: test updates and poisoning together, and score the retrieved evidence, not only the answer.
- **Action signal:** `compare`

### 11. Evidence-Guided Recovery for AI Agents with Ambiguous Tool Outcomes and Partial Execution

- **Authors/org:** Genliang Zhu, Xiaobo Chen, Ziyuan Wang, Chu Wang

### 14. ReplayRCA: Measuring Post-hoc Diagnosis and Live Oversight of Agent Failures by Counterfactual Replay

## Conflicts & open questions

- **Where should action gating live?** Caper (2610.40753) judges observed effects after sandboxed pre-execution, the cross-interface protocol (2610.41397) binds authorization to route and re-checks at commit, and SafeWebWorld (2610.40798) shows predicted futures can look plausible yet lead to wrong EXECUTE/ASK/BLOCK choices. Continues the Oct 31 thread (JevAct decision gate, stale-click checks): prefer observed or re-read state over predictions.
- **Self-evolution keeps underdelivering on learning.** CLR-Bench (2610.40758) finds six self-evolution methods barely beat raw history with a mid model, while EvoMCP (2610.41479), MetaVul (2610.40721) and RoboArchitect (2610.42141) report large gains from evolving data or harnesses against verifiers. External verifiers seem to be what makes evolution pay.
- **Agent self-reports are not evidence.** Module shadowing (2610.40716: denied executions) and the cognitive-module audit (2610.41604: 18/25 modules inert) both say verify from logs and call chains.
- **Search triggering.** BlindToChange (2610.41435) and the search-behaviour audit (2610.41124) agree agents often don't search unless cued; Context as Infrastructure (2610.41172) says that once they do search, a grep-level harness is already accurate, so the open problem is when to search, not how.
