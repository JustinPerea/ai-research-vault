### 1. ReFold: Training-Free Reversible Inter-Turn Context Folding for Long-Horizon Agents
- **Source:** arXiv (cross-list)
- **Link:** https://arxiv.org/abs/2610.07863
- **Authors/org:** Yupeng Su, Jiayi Tian, Zheng Zhang et al. (4 authors)
- **Focus area:** context management / long-horizon
- **What it is:** Training-free rendering layer that keeps the full interaction history but compresses only the rendered context: content an earlier turn already displayed becomes a stub, and turns the agent reports finished fold into a one-line note. Chunked rendering rewrites the cached prefix only every few steps; every removal is reversible from history. Across five long-horizon benchmarks and two frontier LLMs: up to 2.5x fewer tokens, half the KV-cache per session, no drop in success; avoids up to 92% of forced compactions under capped budgets; up to 1.7x faster and 3.4x cheaper under concurrent serving.
- **Why it matters for Justin's agents:** Drop-in for ReAct-style loops: stub repeated tool output and fold finished turns instead of summarizing — keeps prefix caches valid and nothing is lost permanently.
- **Action signal:** `try-now`

### 2. Stateless Language Agents: Scaling Long-Horizon Automated Research
- **Source:** arXiv (cross-list)
- **Link:** https://arxiv.org/abs/2610.07625
- **Authors/org:** Qizheng Zhang, Changxiu Ji, Isaac Sun et al. (18 authors)
- **Focus area:** harness / long-horizon state
- **What it is:** 'Stateful search with stateless agents': no agent carries its conversation across invocations; the harness owns research state (candidates + measured outcomes) and rebuilds a fresh role-specific context each call. - **Why it matters for Justin's agents:** Strong argument for keeping durable state in the harness (files/DB) and handing sub-agents a constructed context rather than a growing transcript.

### 4. One Step at a Time: Trading LLM Autonomy for Process Predictability
- **Source:** arXiv (cross-list)
- **Link:** https://arxiv.org/abs/2610.07817
- **Authors/org:** Hans Schabert, Christoph Peters
- **Focus area:** MCP / process control
- **What it is:** Delivers a procedure one step at a time from an MCP server; each step returns a structured step_output, so the execution path is fixed in advance and logged. Over 15,475 trials on 13 SOP-Bench domains with four open-weight executors (Kimi K2.5 to Ministral 3 8B): process adherence rises from 76-95% to 95-99%, ungrounded correct answers fall from 2.1-4.5% to 0.2-0.3%, and the 8B executor gains +6.5 pp grounded accuracy. Under prompt delivery, 31-49% of correct know_your_business answers skip the SOP entirely.
- **Why it matters for Justin's agents:** A concrete MCP pattern for Mitamaton's repeatable admin flows: serve the procedure step-wise instead of pasting it into the system prompt — especially for small local models.

### 6. SquidAgent: Parallelize Wisely, Coordinate Efficiently

## Conflicts & open questions

- **Raw experience vs distilled rules:** Learn2Play Bench (2610.08215) finds complete action/feedback records beat summarized rules and AMBER (2610.07118) wins with append-only memory, while DAEDALUS (2610.08048) and MINDSET (2610.08586) gain from distilled heuristics and versioned schemas. SkillPoison (2610.07645) shows the distillation step itself is attackable (95.71% success from task-correct experiences). Open: keep raw logs as ground truth and treat distilled rules as a revocable cache?
- **Does persistent memory pay?** Persistent Memory in Multi-Agent Inference (2610.07782) measures no detectable accuracy change from a persistent trace tier (+0.015, CI spans zero) and ServeLearnBench (2610.07792) finds continual adaptation can degrade correct behavior, while DAEDALUS (+15.9 pts), AMBER (+4.09 pp) and NP-Bench's cross-session memory (repeat-mistake rate 1.00 → 0.00) report clear gains. Likely reconciliation per 2610.07782: memory helps only when tasks actually share evidence; single-question benchmarks can't show it.
- **Context strategy for sub-agents:** SquidAgent (2610.08647) forks workers from the orchestrator's full session to avoid re-exploration, while Stateless Language Agents (2610.07625) rebuild a fresh, focused context for every call and report 84%+ token savings. Both beat their baselines; which wins likely depends on task length (minutes vs a billion-token search). Untested head-to-head.
- **Compaction:** ReFold (2610.07863) avoids up to 92% of forced compactions via reversible rendering, while the TRACE study (2610.08722) finds history-based triggers predict compaction harm only weakly (AUROC 0.66). Neither compares against a plain token-budget rule at matched retention.
- **Guards are not free:** Gate stacking (2610.07359), DEFER1 (2610.07657; 78% of blocks deterministic) and APEX (2610.06966; 0% ASR) favor deterministic/contract checks at the action boundary, but POLAR (2610.08082) improves only 8 of 18 model-domain cells and regresses stronger agents, and ParanoiaEval (2610.08662) shows over-defensive behavior in 11.2-58.7% of runs. The utility cost of guards is under-measured.
- **Evaluation design flips conclusions:** quantization verdicts reverse with prompt/scorer (2610.07781), a memory-tier benefit vanished after four measurement corrections (2610.07782), a judge served by an unrequested model version overturned an analysis rule (2610.07359), and only 22.6% of recorded passes clear all Trust Layer checks (2610.07274). Treat single-configuration agent results today as provisional.
