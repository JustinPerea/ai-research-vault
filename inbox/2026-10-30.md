- **Claude Code:** v2.1.314 — adds `permissions.blockWritesOutsideWorkingDirectories` (Write/Edit/NotebookEdit refuse paths outside working dirs in every permission mode), IdP `groups` routing and Bedrock `guardrail_trace` on the Claude apps gateway, idle compaction for 200K+ token idle conversations in VS Code and Desktop, effort-cap auto-retry, and `claude -p` now exits 1 with an error on startup failure — the write fence and the `-p` exit code fix matter directly for unattended harness runs.
