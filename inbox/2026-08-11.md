# AI Research Digest — Tuesday, August 11, 2026

## TL;DR
- **VibeLifeBench** [arxiv:2608.10875] (Xiaohongshu Dots + Evolvent) is the life-agent eval: 200 multi-week tasks × 10 everyday domains in a 22-service simulated world that advances on its *own* clock, with silent changes the agent must re-inspect to notice. Graded on end state, timeliness, and implicit constraints, from artifacts the agent left behind — not from its prose. Seven frontier models, all score low. This is Mitamaton's job description as a benchmark.
- **SPIEval** [arxiv:2608.10692] is the mobile-assistant eval over *scattered* personal information: 250 human-curated tasks, 4,335 records, 10 apps, 21 tools, five cognitive skills (reasoning / disambiguation / integration / preference inference / multi-intent). Best model (GPT-5.5 xhigh) **57.3%**; worst **16.4%**. **79%** of failures are inaccurate information localization — the model commits to a plausible record instead of retrieving more. <2% of retrieval actions use advanced search.
- **Better, Faster, Stronger / SpeedRunner** [arxiv:2608.11338] (Khashabi / Andrews): among skill-learning strategies, **skills-as-programs** cut cost best. SpeedRunner is a coding agent that reads trajectories and refactors skills for the next task, no replay/validation required if the agent can analyze the log. Across three embodied environments it sits at the frontier of learning *and* cost, and holds under distribution shift and randomness. The Bitter Lesson of Tool Calling (Thu) applied to skills.
- **MobileMem** [arxiv:2608.13606] (Zhejiang / Ningyu Zhang, same group as OneDayAgent) is a year-scale on-device memory benchmark: heterogeneous, multimodal, evolving mobile experiences; text + multimodal tracks for multi-hop / temporal reasoning, knowledge updating, implicit preference. Memory as *experience*, not fact retrieval. The iOS-shaped eval for Mitamaton.

## Items

### 1. VibeLifeBench: Can Your Life Agent Be Proactive and Persistent in a Living World?
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2608.10875
- **Authors / org:** Xiaohongshu Dots Studio / Evolvent AI
- **Focus area:** Personal / life agents (proactivity + persistence)
- **What it is:** Argues existing assistant evals are short, self-contained, static. Real life-assistance: tasks last weeks, the world changes while the agent is not being prompted, many constraints are never stated. The agent must decide when to act, when to ask, and when to stay silent; notice unannounced changes; keep one plan coherent. VibeLifeBench: 200 long-horizon tasks, ten everyday-life domains, 22 mock services, scripted multi-week timelines. World clock advances independently; many changes are silent. Scoring: fine-grained weighted checks over *what the agent left behind* (end state, timeliness, implicit constraints) — not the dialogue. Seven frontier models, all low. Tasks, environment, and eval framework to be open-sourced.
- **Why it matters for Justin's agents:** This is Mitamaton, named. The three-way act / ask / stay-silent gate is the product decision; the silent-world-change design is why a "daily digest that only runs when Justin types" will fail (calendar moved, flight delayed, someone else booked the room). Build the eval before the feature: a 10-task personal VibeLife set that scores leftover artifacts (the reminder that was actually created, the message that was actually sent) and penalizes both missed silent changes and unsolicited noise.
- **Action signal:** `compare` — draft 10 Mitamaton tasks with a silent mid-week change and score leftover artifacts; do not use chat quality as the metric.

### 2. SPIEval: Evaluating Large Language Models as Mobile Assistants over Scattered Personal Information
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2608.10692
- **Authors / org:** Junjie Ye / Zhuohui Sheng / Shaofan Liu / Yulun Zhu / Wenjie Fu / Dingwei Zhu / Ming Zhang / Yujiong Shen et al.
- **Focus area:** Mobile personal assistants (cross-app information)
- **What it is:** Human-curated benchmark for using personal information scattered across apps. Five cognitive capabilities: reasoning, disambiguation, integration, preference inference, multi-intent decomposition. 250 tasks, 4,335 personal records, 10 apps, 21 tools, multi-turn. Nine LLMs. Best: GPT-5.5 (xhigh) **57.3%**; weakest **16.4%**. Error analysis: **79%** of failures from inaccurate information localization — commit to a plausible record rather than keep retrieving. <2% of retrieval actions use advanced search; search efficiency varies a lot across models. Data + code: https://huggingface.co/datasets/Junjie-Ye/SPIEval
- **Why it matters for Justin's agents:** Mitamaton on iOS will live in exactly this mess (Calendar + Mail + Messages + Reminders + Files). The 79% localization-failure number is the design constraint: **force a second retrieval / confirm step before acting on a "found" record**, especially for anything side-effecting. The <2% advanced-search figure is permission to expose fielded search (SIEVE-style, or even just `date:` / `app:` filters) instead of hoping the model invents it. Pair with SARA [arxiv:2608.27146]: a wrongly localized recipient is an authorization bug, not just a QA miss.
- **Action signal:** `try-now` — add an explicit "confirm the record (app, id, quote) before write" step to the 3–5 side-effecting Mitamaton tools.

### 3. Better, Faster, Stronger: Programmatic Skill Learning Best Reduces Agent Cost
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2608.11338
- **Authors / org:** Zixi Huang / Xiheng Wang / Andrew Wang / William Jurayj / Bernal Jiménez Gutiérrez / Daniel Khashabi / Nicholas Andrews — Johns Hopkins
- **Focus area:** Agent skills as programs (cost, not just accuracy)
- **What it is:** Asks which skill-learning strategy *saves cost*, not which raises the score. Claim: skills-as-programs win, because a deterministic action sequence replaces long-horizon trial-and-error. Skills can be learned at inference time from past trajectories without replay or validation, if the agent can analyze those logs. SpeedRunner: a coding agent that reads trajectories and refactors skills for future tasks. Three embodied environments: frontier on both learning and cost reduction; robust to distribution shift and environmental randomness.
- **Why it matters for Justin's agents:** Ties Thursday's Bitter Lesson (programmatic tool calling) to the skill layer. A Mitamaton "prep tomorrow" skill that is a *script* (with a SARA-gated send at the end) will be cheaper and less drift-prone than a SKILL.md the model re-interprets every morning. SpeedRunner's "no replay required if you can read the log" is the Claude Code version: after a successful session, have the agent propose a *program* refactor of the skill, not a longer markdown. Keep authorization out of the program's free-for-all — programs are how you get cost, not how you get permission.
- **Action signal:** `try-now` — convert one recurring Claude Code / Mitamaton skill into a checked-in script with a single gated side-effect; compare tokens and misses against the markdown version for a week.

### 4. MobileMem: Learning from a Year of Mobile Experiences
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2608.13606
- **Authors / org:** Xinle Deng / Yida Xue / Xiangyuan Ru / Yijun Chen / Buqiang Xu / Mingjun Mao / Xinjie Liu / Haoming Xu / Shuofei Qiao / Mengru Wang / Chen Jiang / Yuchen Eleanor Jiang / Lizhong Wang / Jason Wang / Li Zeng / Haofen Wang / Guilin Qi / Huajun Chen / Ningyu Zhang — Zhejiang University
- **Focus area:** On-device long-term memory (mobile / experiential)
- **What it is:** Benchmark + framework for on-device long-term memory over year-scale mobile experiences. Knowledge-grounded synthesis builds coherent, temporally consistent long-horizon trajectories from user–app sessions. Complementary text and multimodal settings: multi-hop and temporal reasoning, knowledge updating, implicit preference inference. Framed as remember-the-past / understand-the-present / adapt-to-the-future. Explicitly moves the target from "retrieve the fact" to "learn from the experience."
- **Why it matters for Justin's agents:** Same lab as OneDayAgent (Thu), now on the *memory substrate* for a phone. Combined with SPIEval (scattered apps) and VibeLifeBench (weeks-long silent world), this is the third vertex of the Mitamaton eval triangle: **can the on-device store support temporal + preference questions over a year of phone life.** Activity Frames (Fri) is the compiler you might feed; MobileMem is the question set. Abstract does not publish a headline number — treat it as the dataset/protocol to run, not as a SOTA claim.
- **Action signal:** `compare` — once the tasks land, run the text track against whatever Mitamaton memory store exists (Obsidian notes vs compiled frames) before adding multimodal.

## Conflicts & open questions
- **Conflict flagged (programmatic vs markdown skills):** SpeedRunner + Bitter Lesson (Thu) say programs beat JSON/markdown for cost and drift. Skill-Use (Wed), SkillProx (Fri), SkillJack (Wed), WikiSkill (vault 2026-08-28) all assume textual `SKILL.md` under progressive disclosure. These are not the same artifact. A Mitamaton skill that is a *program* will fail Skill-Use's Trigger/Compliance scoring and will also be a juicier SkillJack persistence target (a backdoored script is worse than a backdoored paragraph). Split the library: programs for recurring deterministic work; markdown for judgment.
- **Convergent life-agent triangle:** VibeLifeBench (proactive weeks) + SPIEval (scattered apps, 79% localization failures) + MobileMem (year-scale experiential memory) + OneDayAgent (2026-08-04 harness) are one product. No paper evaluates all four together. That combined 15-task set *is* the Mitamaton eval.
- **Open question vs PAST-Bench (2026-08-04):** VibeLifeBench scores leftover artifacts in a living world; PAST-Bench scores pathway evidence under fresh sessions. A Mitamaton win should have to pass both.
