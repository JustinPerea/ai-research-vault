## Conflicts & open questions
- **Harness vs model (Occamy vs 11987):** Occamy-1.0 ([`2609.11977`](https://arxiv.org/abs/2609.11977)) further-trains a co-work model across multiple harnesses for Pareto cost–performance; Harness or Model? ([`2609.11987`](https://arxiv.org/abs/2609.11987)) finds **no average native-harness advantage** on same-model contrasts (and opposite strata on repo vs contest). Do you buy a better base+harness-trained model, or keep swapping harnesses on frontier APIs?
- **AIM shared multi-user memory vs privacy:** AIM ([`2609.12320`](https://arxiv.org/abs/2609.12320)) classifies private vs public memory with index-level ACL (96% visibility accuracy on MUMBench) — but any shared household/team memory for Mitamaton still expands the blast radius if classification errs. Hard privacy default vs useful shared knowledge?
- **LifeFuse lifecycle memory vs CORE selective persona update:** LifeFuse-Mem ([`2609.12436`](https://arxiv.org/abs/2609.12436)) separates durable vs temporary **writes** via lifecycle labels; CORE ([`2609.12373`](https://arxiv.org/abs/2609.12373)) separates turn-local evidence from persistent **persona-state revision** under uncertainty.
