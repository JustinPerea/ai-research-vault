## News and changelogs
- **OpenRouter:** Tutorial on reranking in RAG: take vector search's top 30 candidates and re-score each chunk against the question with a dedicated cross-encoder, fixing near-miss retrievals — a cheap accuracy fix for memory/retrieval layers in agents. [link](https://openrouter.ai/blog/tutorials/reranking-rag/)
- **Supabase:** Accounts get backup sign-in options: a password for accounts that sign in with GitHub, ChatGPT or another OAuth provider, and MFA recovery codes, set up in Account Security — account-recovery hygiene for the hosting/database side, no agent angle. [link](https://supabase.com/changelog/account-backup-sign-in)
- **Claude Code:** v2.1.323 adds Code Mode, an experimental opt-in where Claude writes JavaScript to call its tools (can be turned off per organization); `engines["claude-code"]` in `plugin.json` so plugins outside their version range aren't installed or loaded; TypeScript hook type checking in `claude plugin validate` (`--strict` fails on findings); `CLAUDE_CODE_AUTO_MODE_MODEL` in managed settings; a 30-second progress heartbeat while long hooks run in `claude -p` and SDK sessions; and `.docx` Artifact support — Code Mode changes how tool-heavy MCP sessions execute, and the heartbeat matters for headless `claude -p` jobs with slow hooks. [link](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)
- **LangChain:** Essay arguing companies must own their agent systems, governance, context and feedback loops to turn generic AI into lasting advantage — opinion piece, no product change. [link](https://www.langchain.com/blog/own-your-intelligence)
- **Anthropic API:** Self-hosted Claude Managed Agents launched: you run the whole Managed Agents service (not only sandboxes) on your own infrastructure and store agents, sessions and session history there; model requests go to the provider you choose (Anthropic by default); access via your Anthropic account team — session persistence and data residency under your control for managed agent deployments. [link](https://platform.claude.com/docs/en/release-notes/overview#self-hosted-managed-agents)
- **OpenAI:** Commits $2 million to research on AI and children's safety, supporting shared tools to measure risks and opportunities for young people — a safety/policy signal for consumer apps, no API change. [link](https://openai.com/index/children-first-declaration)
- **Gemini API:** Gemini 4 Hydrogen (`gemini-4-hydrogen`) is GA for everyday coding and agentic workflows, on the free tier and at $1.50 / 1M input and $7.50 / 1M output tokens, adds a fourth `xhigh` thinking level, and is now the default model for the Antigravity agent in Gemini Managed Agents; migration guidance from Gemini 3.8 Flash — a cheaper fast-tier option to compare for agent loops. [link](https://ai.google.dev/gemini-api/docs/changelog#11-12-2026)
- **Vercel:** Gemini 4 Hydrogen and Inkling 2 Small are now available on AI Gateway — both reachable through Gateway routing (no details in the feed). [Gemini 4 Hydrogen](https://vercel.com/changelog/gemini-4-hydrogen-now-available-on-ai-gateway), [Inkling 2 Small](https://vercel.com/changelog/inkling-2-small-now-available-on-ai-gateway)
- **Composio:** Gmail (`GMAIL_NEW_GMAIL_MESSAGE`, `GMAIL_EMAIL_SENT_TRIGGER`) and Google Calendar triggers now fire in seconds via Google push notifications instead of polling, with the same payload shape; on Composio-managed auth nothing to set up, and the upsert response's `type` says webhook vs polling — event-driven email/calendar triggers for a day-admin agent like Mitamaton. [link](https://docs.composio.dev/docs/changelog/2026/11/12)
