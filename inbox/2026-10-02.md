## Conflicts & open questions

- **Harness evolution vs harness trust:** ActiveSaddler / VeriHarness / GUI-HARVEST push autonomous harness improvement, while When Harnesses Lose the Signal, Chaining Skills to Hijack, and Empty Commitments show harness/skill surfaces as failure and attack paths.
- **Memory retention vs retrieval vs belief:** What Should an Agent Remember separates retention from retrieval; Heavy-Tailed Memory / MemFit / Mem++ / CAVE-Mem optimize memory systems; Beyond Memory argues explicit belief states beat raw memory dumps — Mitamaton needs a clear retention/retrieval/belief split.
- **Local-first small models vs frontier harnesses:** Mingbird and K-Dense BYOK bet on local open models; Microtask Eligibility and Finding the Right Fit say model–harness pairing dominates — do not assume a frontier API is required for day-admin microtasks.
- **Tool receipts vs capability enforcement:** Actions with Receipts, PACE, Auditing Action Settlement, and Authorization for Self-Modifying Agents all want auditable tool effects; Deny Without Disabling prefers soft auth — Mitamaton MCP graph needs both receipting and least-privilege.
- **Multi-agent local correctness vs global coherence:** Worse Together / Global Coherence / Pay for the Fault show teams failing despite locally correct agents — multi-agent Mitamaton+Claude Code loops need global semantic checks, not only per-agent success.
- **Long-horizon eval realism:** ReLiveGym (weeks of replayed reality), DAYJOB (professional work), and Agent Evaluation Reliability disagree on whether more tasks, more scaffolds, or longer lived environments fix ranking noise.
