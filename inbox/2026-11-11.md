### 1. When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2611.14326
- **Authors/org:** Runxuan Tang, Haoyu Gao, Yuyan Ding et al.
- **Focus area:** memory admission / self-evolution
- **What it is:** FGSE treats each experience-derived lesson as a hypothesis (precondition, behavior change, expected effect, verifier), applies it only in temporary state, and commits, refines or rejects it after target-transfer, falsification and archived-regression probes. Reports 39.8 WebArena SR, 78.8 AppWorld completion, 0.724/0.487 Pass^1 on tau-Retail/tau-Airline, with harmful committed updates cut to 3.6% and regression damage to 1.3%.
- **Why it matters for Justin's agents:** A concrete gate for when a day-admin agent may write a lesson into persistent memory: test it before it sticks.
- **Action signal:** `try-now`

### 2. Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2611.14320
- **Authors/org:** Yukyeong Lee, Yumin Choi, Jinheon Baek et al.
- **Focus area:** evidence-linked memory
- **What it is:** WikiTrace stores each lesson as a short insight linked to a summary of why its trajectory succeeded or failed and to the raw trajectory; when an insight is thin, conflicting or from a failed task, the agent descends the links with terminal tools before acting. Beats prior memory approaches on five agentic benchmarks and reduces memory-induced degradation (code released).
- **Why it matters for Justin's agents:** Directly addresses agents getting worse with memory; keep provenance links from every distilled lesson back to its trace.
- **Action signal:** `try-now`

### 3. Agent Architecture Cost-Success Trade-offs: A Controlled Evaluation across Enterprise-Style SOPs
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2611.12953
- **Authors/org:** Subhrangshu Nandi, Hitesh Arora, Yunfei Bai et al.
- **Focus area:** single vs multi-agent / skills cost
- **What it is:** Controlled comparison of four architectures (function-calling single agent, skill-augmented agent, centralized multi-agent, triage swarm; eight arms) on 13 enterprise SOPs with fixed model/tools. No architecture is separable in aggregate; coordinated arms spend 1.4-4.7x tokens and 2.6-5.8x latency; high-quality skills lift success 67.4% to 73.1%, degraded skills fall below baseline; only a redesigned multi-agent arm significantly beats single agent (75.6%).
- **Why it matters for Justin's agents:** Evidence for keeping a single agent plus good skills as the default and spending effort on skill quality, not orchestration.
- **Action signal:** `compare`

### 4. Coding Agent Memory Post-Training II: Unlocking the Memory Potential of Pre-trained File Operations for Long-Horizon Tasks via On-Policy Distillation
- **Source:** arXiv (cross-list)
- **Link:** https://arxiv.org/abs/2611.14009
- **Authors/org:** Lirui Luo, Kelong Mao, Xinwei Yang et al.
- **Focus area:** file-based memory post-training
- **What it is:** CAMG-II gives long-horizon RL environments (Shop, Coding, AutoResearch, General, Visual) plain Bash plus an episode-persistent workspace so the policy uses files as memory across context replacements; CAMP-II trains one policy across all five with asynchronous on-policy distillation from a teacher with a file-operation prior. 2.97x the gain of the strongest OPD baseline; transfers to Terminal-Bench 2.1 and SWE-Bench Pro V2.
- **Why it matters for Justin's agents:** Supports the plain-files-as-memory pattern Claude Code already uses over bespoke memory tools.
- **Action signal:** `track`

### 5. From Attack Surface to Defense Architecture: Compositional Security for Agentic Coding Harnesses
- **Source:** arXiv (cross-list)
- **Link:** https://arxiv.org/abs/2611.13960
- **Authors/org:** Simon Hegelich, Bardh Prenkaj, Habiba Sarhan et al.
- **Focus area:** harness security
- **What it is:** ActiveSecHarness: a reference monitor separating intelligence from authority, with HMAC capability tokens across four trust rings, a 2D trust x sensitivity taint lattice plus workspace provenance ledger, and deterministic Ring-0 OS/tool guards. On 252 fixtures a live qwen3:4b judge refused 98.3% of benign work at 142.3 ms, while Ring 0 blocked all attacks with 0 false positives in 12.7 microseconds; the lattice caught all 12 kill chains.
- **Why it matters for Justin's agents:** Another data point that deterministic, capability-based guards beat LLM judges for shell/curl tool calls in coding harnesses.
- **Action signal:** `compare`

### 6. Dependable Long-Horizon LLM Agents: A Trajectory-Centered Empirical Study of Where Errors Enter and Which Controls Reach Them
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2611.13254
- **Authors/org:** Shaohuang Wang, Jinghao Wen, Xulei Zhang et al.
- **Focus area:** long-horizon failure analysis
- **What it is:** Episode records trace each fault from origin through propagation, detection and response; applied to 95 failed runs of six multi-agent systems (Who&When, MAD). Faults enter early (median 0.18 of the run); in 72% of failed runs the trajectory already contained contrary evidence, and in 88% of those no agent acted on it; 45% of hand-crafted Who&When failures ended in a provider content-filter crash after which the harness emitted an answer no agent produced.
- **Why it matters for Justin's agents:** Argues for re-checking beliefs against the environment and task contracts fixed at admission, and for harnesses that never fabricate a final answer after a provider error.
- **Action signal:** `track`

### 7. Synapse-Control: Making Agent Experience Actionable with Lightweight Runtime Control
- **Source:** arXiv (cross-list)
- **Link:** https://arxiv.org/abs/2611.13615
- **Authors/org:** Zhiyuan Huang, Shengan Zheng, Chenghu Yang et al.
- **Focus area:** runtime control / experience reuse
- **What it is:** Synapse-Control replaces generative failure diagnosis with a lightweight control plane: rules shortlist advice, a fine-tuned 1.7B classifier scores it, micro-contracts check arguments, and a Prompt Value Table enforces cooldown and token budgets. Across 1,308 attempts per method on AppWorld and WebShop: 270 successes (29.8% over Base), 4,987 diagnosis calls replaced, auxiliary control time cut ~50% vs Sentry.
- **Why it matters for Justin's agents:** A cheap, small-model control plane for when to inject past-run advice, a fit for local models.
- **Action signal:** `compare`

### 8. ReTrace: Distilling Tool-Using Agents into Planner-Free Workflows
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2611.14492
- **Authors/org:** Kaiyuan Hou, Yang Ping Kuo, Indranil Bhattacharya et al.
- **Focus area:** agent-to-workflow distillation
- **What it is:** ReTrace turns an SOP plus a few logged agent runs into an executable workflow where code, not an LLM, picks the next step, using the reasoning text written with each tool call to extract step conditions. On 79 production procedures: 93.8% completion vs 96.8% for the agent at 24% lower cost; on tau^2-Bench 75.8% vs 80.6% but 1.3s instead of 170s.
- **Why it matters for Justin's agents:** Recurring day-admin routines can be compiled out of the LLM loop once traces exist.
- **Action signal:** `try-now`

### 9. Teaching the Harness: Student-Aware Skill Transfer for LLM Agents

- **Link:** https://arxiv.org/abs/2611.13144
- **Authors/org:** Chang Liu, Bo Wu

### 11. Bursts That Outlast Themselves: Persistent Degradation in Prefix-Cached Agent Serving
- **Source:** arXiv (cross-list)
- **Link:** https://arxiv.org/abs/2611.13412
- **Authors/org:** Wen Huang, Jack Liu
- **Focus area:** agent serving / prefix cache
- **What it is:** Prefix-cached agent serving is metastable: a few minutes of extra arrivals leave vLLM at ~10% hit ratio and about half throughput for the remaining 70 minutes (9 of 12 pairs), also on SGLang and Qwen3-32B with SWE-bench traces. Throttling admissions recovered 1 of 7 collapsed runs; suspending sessions against a capacity limit recovered all; a KV-demand budgeter prevented the failure in every run.
- **Why it matters for Justin's agents:** Matters for any self-hosted local model serving long agent sessions: bound resident KV per active session.
- **Action signal:** `track`

### 12. From Questions to Decisions: Benchmarking How LLM Agents Acquire Decision-Relevant Information from Human Beings

- **Authors/org:** Yuhan Tang, Ke Fan, Xinkai Zou et al.
