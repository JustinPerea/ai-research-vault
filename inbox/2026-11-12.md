## News and changelogs
- **LangChain:** How LangChain built its GTM Agent on Deep Agents to produce consistent, custom sales artifacts grounded in business context — a worked example of a Deep Agents build for document-producing agents. [link](https://www.langchain.com/blog/gtm-agent-high-quality-sales-artifacts)
- **OpenRouter:** Tutorial on agents stuck in infinite loops: the model keeps calling a failing tool with the same arguments because nothing in the loop tells it to stop, and each retry resends the whole conversation, so an overnight loop can cost thousands of dollars — argues for loop guards and retry caps in any agent harness. [link](https://openrouter.ai/blog/tutorials/ai-agent-infinite-loop/)
- **OpenRouter:** Guide to benchmarking LLMs on your own inputs and output formats, comparing graded accuracy, billed cost and request time; on its 60 synthetic tasks GPT-6.1 Sol passed 180/180 trials across three repeats — a template for picking models per agent task. [link](https://openrouter.ai/blog/tutorials/how-to-benchmark-llms/)
- **OpenRouter:** OpenRouter now runs in 8 languages; post covers the translation pipeline, its cost, and how reader reports become fixes — a self-correcting content pipeline, little direct agent-platform angle. [link](https://openrouter.ai/blog/announcements/openrouter-in-8-languages/)
- **OpenRouter:** Self-hosted open-weight model vs API: GPU rent is charged every hour busy or idle, while an API charges only per token — relevant to deciding when local/open models for agents pay off. [link](https://openrouter.ai/blog/insights/self-hosted-llm-vs-api/)
- **Gemini API:** Released Gemini Decision (`gemini-decision-1`) and the Decisions API for fast, calibrated binary, categorical and rubric decisions across text, images, audio, video and PDFs with zero output tokens — a cheap classifier/router/guard primitive for agent pipelines. [link](https://ai.google.dev/gemini-api/docs/changelog#11-11-2026)
- **Vercel:** Gemini Decision 1 now available on AI Gateway — the same decision model reachable through AI Gateway routing (no details in the feed). [link](https://vercel.com/changelog/gemini-decision-1-now-available-on-ai-gateway)
- **Gemini API:** Gemini 4 Carbon (`gemini-4-carbon`) is generally available, positioned for sustained agentic coding, multimodal knowledge work, scientific reasoning and cybersecurity defense, at introductory pricing of $2.00 / 1M input and $10.00 / 1M output tokens through November 30, 2026 — a new frontier option to compare for long-running coding agents. [link](https://ai.google.dev/gemini-api/docs/changelog#11-10-2026)
- **OpenRouter:** Extractions API pulls typed fields from documents and images (name the fields, get values, spans and confidence back); three models serve it at launch — structured extraction as a hosted tool for document-ingesting agents. [link](https://openrouter.ai/blog/announcements/extractions-api/)
