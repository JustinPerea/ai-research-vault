### 1. Position: It is Time to Virtualize Foundation Models with a Self-evolving Operating System Layer
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2609.19203
- **Authors/org:** Suparna Bhattacharya, Tarun Kumar, Cong Xu, Satish Kumar Mopur, Jiahao Li, Ashish Mishra et al.
- **Focus area:** runtime / MCP / memory OS
- **What it is:** AI applications have shifted from single, monolithic foundation models (FM) to compound agentic systems. Yet today's stacks remain fragmented: even as protocols (e.g., MCP, A2A) ease tool/agent connectivity, each framework embeds an implicit runtime for state, memory, budgets, and guardrails, making behavior non-portable and governance brittle.
- **Why it matters for Justin's agents:** Position paper arguing FMs need a self-evolving OS layer (memory, MCP tools, agent scheduling) — blueprint language for Mitamaton + local harness.
- **Action signal:** `try-now`

### 2. An Architecture for Long-Horizon Agents: Levels, Ticks and Cascaded Intelligence
- **Source:** arXiv (new)
- **Link:** https://arxiv.org/abs/2609.19519
- **Authors/org:** Erik Nijkamp, Anurag Koul, Egor Pakhomov, Bo Pang
- **Focus area:** long-horizon architecture
- **What it is:** Language-model agents are increasingly asked to carry out work spanning days or weeks, such as an operations remediation or a research programme. Such a task outlives any context window, any process and any interval at which a person can attend. - **Link:** https://arxiv.org/abs/2609.19425
- **Authors/org:** Laxmipriya Ganesh Iyer

- **What it is:** Tool-augmented large language model (LLM) agents fail in a way no tool-selection or tool-security method addresses: they call tools that do not exist and pass arguments no schema declares. ## Conflicts & open questions
- **Harness value vs harness bloat:** How Do Agent Harnesses Create Value ([`2609.20474`](https://arxiv.org/abs/2609.20474)) and the empirical harness study ([`2609.20804`](https://arxiv.org/abs/2609.20804)) argue harness design is the product — but SoL-Pi ([`2609.20519`](https://arxiv.org/abs/2609.20519)) and self-improving coding agents ([`2609.19526`](https://arxiv.org/abs/2609.19526)) push recursive auto-loops that can grow harness surface without clear release control.
- **Skill write admission:** SkillAA ([`2609.20455`](https://arxiv.org/abs/2609.20455)) wants attribution + validation + rollback on skill-graph updates; EconSkills ([`2609.19523`](https://arxiv.org/abs/2609.19523)) stresses transfer/retrieval. For Mitamaton: every skill write needs a rollback path, not just a store.
- **More agents vs fewer:** Rethinking Multi-Agent Collaboration ([`2609.19759`](https://arxiv.org/abs/2609.19759)) warns more can be less; ClashBench ([`2609.19892`](https://arxiv.org/abs/2609.19892)) and MAGS ([`2609.19391`](https://arxiv.org/abs/2609.19391)) show multi-agent conflict and the need for formal safety. Default to single-agent + tools unless interference is measured.
- **Context compression sufficiency:** Correct Now, Insufficient Later ([`2609.20045`](https://arxiv.org/abs/2609.20045)) vs Self-Evolving Search Index ([`2609.19656`](https://arxiv.org/abs/2609.19656)) / AdaRepair-Mem ([`2609.20130`](https://arxiv.org/abs/2609.20130)) — compress for the next turn, or retain recoverable experience for later tasks?
- **Commit authority:** When AI Agents Commit ([`2609.20261`](https://arxiv.org/abs/2609.20261)) demands serializability across data/evidence/policy/authority; Closed-World tool resolution ([`2609.19425`](https://arxiv.org/abs/2609.19425)) fights tool hallucination. Day-admin actions that touch calendar/mail need both.
