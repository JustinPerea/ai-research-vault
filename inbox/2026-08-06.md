## Items

### 1. Recursive Synthesis for Long-Horizon Terminal Tasks (RST)
- **Source:** arXiv (Hugging Face Daily Papers)
- **Link:** https://arxiv.org/abs/2608.05466
- **Authors / org:** Zhongzhi Li / Yucheng Shi / Zongxia Li / Ruhan Wang / Anhao Li / Zixun Huang / Junyao Yang / Lei Ke / Ninghao Liu / Haitao Mi / Leowei Liang
- **Focus area:** Terminal-agent data + long-horizon eval
- **What it is:** Recursive verified synthesis of terminal-agent tasks. From verified seeds: extend the reference solution, realign verifier + instruction, validate in a fresh sandbox, reuse accepted tasks as seeds. 15 rounds → 37,484 tasks at ~$0.05 each. Difficulty climbs: median reference solution 67 → 374 lines, median executed commands 40 → 244, DeepSeek-V4-Pro pass@4 90% (R1) → 2.5% (R15). Rejection-sampled Qwen3.5 trajectories → SFT lifts Qwen3.5-27B and Qwen3.5-122B-A10B by up to 10 points on Terminal-Bench 2, Terminal-Bench Hard, and Long-Horizon Terminal Bench. Agentic PPO on the 27B: **49.44% / 32.00% / 22.07%** (+20.0 / +41.2 / +21.9% rel.). After 15 rounds, yield and validation rates stay stable — no ceiling yet.
- **Why it matters for Justin's agents:** Not a Mitamaton feature. It *is* the data engine behind any honest Claude Code / local-terminal eval. If Justin wants a personal Terminal-Bench-like set that does not saturate, RST's "extend solution → realign verifier → sandbox" loop is the recipe; $0.05 vs $100s is the reason it is feasible. Also a warning: published Terminal-Bench numbers (including PILOT [arxiv:2608.26530]) will keep moving as synthetic long-horizon data floods post-training.
- **Action signal:** `compare` — do not train on it this week; bookmark as the generator if the 10-task personal terminal set saturates.

### 2. The Bitter Lesson of Tool Calling
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2608.06370
- **Authors / org:** Ishan Patel / Sahil Sen / Elias Lumer / Vamse Kumar Subbiah
- **Focus area:** Tools & connectors (programmatic vs JSON tool calling)
- **What it is:** Head-to-head of programmatic tool calling (typed Python stubs, model writes a script, execution + results in one agent turn) vs native JSON tool calling on BFCL v4, 14 models, current and prior generations, real-world task conditions. PTC matches or exceeds JSON on **11/14** models; GPT-5.6 family **+10.6%**. Parallel fan-out: 13/14 match or beat. Context-rot: PTC holds while JSON drops **2.3%** on average. Claim: PTC is a viable, generation-tracking alternative, not a niche code-agent trick.
- **Why it matters for Justin's agents:** Claude Code already lives in the "tools as code" world; Mitamaton MCP is closer to JSON. The paper is permission to *prefer scripts that chain/fan-out* over one-tool-per-turn JSON for any code-capable backend (Opus, local Qwen). Practical port: expose Mitamaton tools as a small Python module the agent can import, and only fall back to JSON for the side-effecting calls that SARA-style authorization needs to see one at a time.
- **Action signal:** `try-now` — one Mitamaton workflow (e.g. "prep tomorrow") implemented as a scripted tool chain vs the current JSON loop; score steps, tokens, and misses.

### 3. StepJack: Benchmarking Computer-Use Agent Safety Against Multi-Step Indirect Prompt Injection
- **Source:** arXiv
- **Link:** https://arxiv.org/abs/2608.06477
- **Authors / org:** Zhuoxin Zhan / Akbar Rafiey / Avery Ma / Leila Pishdad / Layla El Asri — BorealisAI
- **Focus area:** Agent security (CUA / multi-step IPI)
- **What it is:** Multi-step IPI: an adversarial goal is decomposed into innocuous-looking sub-steps and planted across a chain of pages the agent is steered to visit. Automatic decomposition pipeline (must still achieve the original goal; each step optimized for innocuousness). StepJack: 480 test examples. Six SOTA CUAs. At fixed depth, multi-step attacks raise ASR on 3/6 CUAs by up to **31.2pp** (GPT-5.4-mini 41.7% → 72.9% at three-step). Averaged over the five CUAs that follow the reference chain (all but EvoCUA-32B): **31.3% → 36.9%**. Code + data: https://github.com/BorealisAI/StepJack
- **Why it matters for Justin's agents:** Claude-in-Chrome / any Mitamaton web tool that follows links is the threat model. A single-page "ignore this injection" eval will miss the attack. Portable defense shape: treat a *navigation path* as the taint unit, not a single observation; require the user objective to support the *final* side-effecting argument (SARA) even if each hop looked fine. Do not enable autonomous multi-hop browsing on Mitamaton until this class is in the eval.
- **Action signal:** `compare` — add a 10-item multi-hop injection set (innocuous hop 1–2, payload on hop 3) before turning on any auto-browse skill.
