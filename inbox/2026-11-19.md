# AI Research Digest — Thursday, November 19, 2026

## TL;DR
- **GUARD** (compare) — Only promote a harness edit when it fixes new failures without breaking previously mastered self-checks.
- **ARISE** (compare) — Accept a new memory rule only if held-out accuracy rises.
- **Thinking Fast, Anywhere** (compare) — Use skill instructions to find enumerable decision points and send them to a small model.
- **Metrics-in-the-Loop** (try-now) — Inject automatically computed code metrics into the agent context during the run.
- **Reducing Inference Cost of Coding Agents with Timeout Cascades** (compare) — Try a cheap small model first with a timeout, and escalate to a larger model only on failure.
- **automodel** (try-now) — Package model discovery as an agent skill rather than a hand-run search.
- **Semantic Context Handoff with On-Demand Evidence for Long-Horizon Agents** (compare) — Hand off a compact semantic state and keep raw action/observation evidence retrievable on demand.
- **MoE-Context** (compare) — Mask irrelevant context blocks in the KV cache rather than deleting and re-prefilling.
- **Resolution as Attention for Efficient Agent Memory Perception** (compare) — Show past interactions at lower resolution unless they are relevant to the next decision.
- **When Single Agent Is Enough** (compare) — Baseline a single agent before adding multi-agent coordination.
- **Dependency Fabrication in Repository Deployment Agents** (compare) — Give agents an explicit rule and a clear stop-and-report path for unresolvable dependencies.
- **Idempotency Is Not Recovery** (try-now) — Keep an action ledger and reconcile after failures instead of relying on idempotent retries alone.
